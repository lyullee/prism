# PRISM CI 실패 원인과 재현 절차 (2026-11-15)

## 이번에 수정한 실패

GitHub Actions의 `Python contracts and numerical checks` 작업에서 두 가지가 실패했다.

1. 격리 packet overlay 예제가 작업공간에서만 존재하는 이전 경로
   `results/20261014/hazop_isolation_packets/...`를 가리키고 있었다. 해당 결과는
   저장소 checkout에 포함되지 않아 Ubuntu runner에서 `FileNotFoundError`가 발생했다.
2. `test_reviewed_signal_unit_evidence.py`가 PDF 검토를 위해 사용하는 `pypdf`가
   테스트 extra 의존성에 선언되어 있지 않았다. 따라서 깨끗한 runner에서
   `ModuleNotFoundError: No module named 'pypdf'`가 발생했다.

## 반영한 수정

- `examples/generic_lh2_isolation_packet_overlay.json`의 12개 packet 경로를
  저장소에 포함된 `results/20261111/native_generic_scope_packets_isolation/events/...`
  경로로 변경했다.
- `pyproject.toml`의 `test` extra에 `pypdf>=5,<7`을 추가했다.
- GitHub Actions의 오래된 action 고정 버전을 현재 major 버전인
  `actions/checkout@v5`, `actions/setup-python@v6`로 갱신했다.

overlay 테스트는 packet의 존재 여부, port ID, 격리 종료 근거와
`provider_packet_promoted=false`를 함께 확인하므로, 경로만 고쳐서 엄격한 시설 QRA로
잘못 승격되는 것을 허용하지 않는다.

## 검증 결과

로컬 패키지 디렉터리에서 다음 명령을 실행했다.

```powershell
python -m pytest -q
```

결과는 **1209 passed, 1 warning**이다. 경고는 Python 3.14에서
`pytest-asyncio`가 사용하는 이벤트 루프 정책 API의 deprecation warning이며 테스트
실패와 무관하다.

wheel 계약도 확인했다.

```powershell
python -m pip check
python -m pip wheel --no-deps --no-build-isolation . -w wheelhouse
```

wheel 안에 `lh2_tno/data/frequency_catalogue.json`, `tno_host.py`와
`prism = tno_host:main` entry point가 포함된다.

수정 커밋의 원격 Actions `Run #941`은 checkout, Python 설치, 의존성 설치, 전체 테스트,
wheel 검증 단계를 모두 통과했다.

## 해석 범위

이 수정은 재현 가능한 CI 환경과 테스트 fixture를 고친 것이다. 시설 방출 경계,
qualified provider, 독립 물리검증, 시설 전체 IR/F-N의 IJHE 승격 상태를 바꾸지 않는다.
