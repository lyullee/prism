# PRISM 수직 handoff 체인 감사 (2026-10-24)

`results/20261024/native_generic_scope_vertical_merged_facility_ledger_population_v3.json`의 수직 vent 5개 사건은 별도 `resolved_release_catalog.json`에 저장된 합성·운영자 제한 방출 기록을 사용한다. 이번 감사는 두 장부를 provider result digest로 연결한다.

재현 명령:

```powershell
python scripts/audit_vertical_handoff_chain.py `
  --campaign-result results/20261024/native_generic_scope_vertical_merged_facility_ledger_population_v3.json `
  --release-catalog results/20261020/vertical_vent_all_bins/resolved_release_catalog.json `
  --base-chain-audit results/20261024/native_generic_scope_vertical_chain_closure_v1.json `
  --output results/20261024/native_generic_scope_vertical_handoff_chain_v1.json
```

현재 결과는 5개 event, 10개 weather case, 10개 risk atom을 모두 digest·방출량·종료시간·최종 피해 원자까지 대조한다. 각 사건의 vertical handoff 상태 이력도 확인한다. 기존 qualified-subset 24개와 합치면 선언된 29개 사건의 진단 체인 연결을 확인할 수 있다.

이 결과의 성격은 `VERTICAL_OPERATOR_LIMITED_CHAIN_CLOSED`이다. 방출 입력은 합성이고 0.37 s 명령 종료를 사용하며, 수직 handoff는 독립 검증되지 않았다. 따라서 qualified provider packet, 현장 빈도, 물리 검증, 시설 전체 IR/F-N 또는 QRA를 생성하지 않는다.
