# IJHE 액화수소시설 위험평가 연구 프로토콜

2026년 10월 8일. 버전 0.3. 현장 사고빈도 자료가 없다는 사용자 확인과 v0.4.0 설비 출구 연결을 반영했다. 로컬 연구계획이며 외부 사전등록·실험 검증 완료를 뜻하지 않는다.

## 연구 질문과 기여

운전 상태와 관측을 조건으로 하면서 액화수소의 방출상 전이·잔존 구름·풀 증발을 보존하면, 정적 대표방출률을 사용한 평가보다 단기 피해영역과 위험변화를 더 잘 설명할 수 있는지 검증한다. 동일한 예측 경로에서 정확도와 실제 처리시간을 함께 측정한다.

목표 논문 제목 후보는 **A conservation-aware framework for sensor-conditioned consequence and short-horizon risk assessment of liquid hydrogen facilities**다. 현재 실시간 요건을 입증하지 않았으므로 제목과 초록에 real-time을 확정 표현으로 넣지 않는다.

새 기여는 시설 내부 열유체–외부 방출/분산의 일관된 경계 전달, 관측 기반 상태 갱신과 방호상태 반영, 시간 조건을 명확히 한 위험계산, 검증된 계산 가속이다. 기존 SLABx-LH2 모델 및 PSEP 투고의 농도 검증 결과는 선행 근거로 인용한다.

## 연구 범위

첫 논문은 일반적인 실외 액화수소 저장·이송·기화·벤트 시설을 다룬다. 센터 태그·2탱크 운전 절차·벤트 설정압을 일반 기본값으로 사용하지 않는다. 실내, 복잡한 장애물, 전체 도미노, vent-line 내부 점화 및 BLEVE는 첫 논문의 검증 범위에 자동 포함하지 않는다.

발생 전 사건강도 기반 위험, 현재 누출 posterior, 이미 관측된 누출의 피해예측, 연간 IR/F–N을 구분한다. 이미 시작된 누출에 연간 누출빈도를 다시 곱하지 않는다. 정상 XV 벤트와 PSV의 비상 작동·고장 사건을 별도 모델링한다.

## 비교군

| 비교군 | 고정해야 할 조건 | 검증할 차이 |
|---|---|---|
| 기존 TNO 정상·peak·질량등가 평균 | 동일 재고·방출/격리·피해 정의 | 과도 이력을 축약한 영향 |
| 연계 LH2 기준 solver | source stage·상·엔탈피·운동량·물성 | 방출–전이–풀–분산의 보존과 영향 |
| 기준 solver와 센서 상태 갱신 | 같은 모델·측정 불확실성·홀드아웃 | 관측이 예측·검출·불확실성을 개선하는지 |
| 온라인 축약 모델 | 동일 입력·관측량·격자/수용점·레짐 | 정확도와 p50/p95/p99 처리시간 |
| HyRAM+ 적용조건 일치 경로 | 동일 실제/가상 노즐 경계·점화·노출 | 외부 물리 benchmark. 적용조건이 다르면 진단 비교로 표시 |

## 데이터 분할과 독립 검증

센터의 ‘원본’에는 그래프/영상 복원 자료가 포함돼 있다. 파일별 원계측·디지타이징·영상 복원·예측·합성 출처를 유지하고, 같은 자료에서 파생된 촘촘한 행을 독립 관측으로 세지 않는다.

날짜 또는 운전 세션 단위로 개발·파라미터 결정·홀드아웃을 분리한다. 온라인 상태 추정은 해당 시각까지의 관측만 사용한다. 미래 시각을 사용한 양방향 보간과 정답 농도 기반 보정은 운영 예측에 사용하지 않는다. 입수된 자료 수와 미확정 시각/압력기준/센서 위치에 따라 분할 목록을 고정한 후 성능을 계산한다.

센터 정상공정 기록은 압력·온도·액위·벤트 상태 응답 검증에 사용한다. 누출 역추정과 외부 피해는 통제누출 또는 정답이 있는 외부 자료를 요구한다. 1분 복원 자료로 sub-second 검출 지연을 주장하지 않는다. FFI 등의 이미 반복 탐색한 자료는 retrospective 평가로 분류하고 새로운 독립 holdout으로 표시하지 않는다.

빈도 검증에는 부품 종류·수·노출기간·운전시간 또는 연결 횟수, 고장 정의와 누락/검열 기록이 필요하다. 그 자료가 없으면 빈도 prior의 민감도 연구를 수행하고 현장 사고빈도를 검증했다고 주장하지 않는다.

## 현장 사고빈도 자료 없이 진행하는 기본 연구 경로

현재 현장 누출사건·설비별 관찰노출 자료는 없으며, 확보를 개발이나 첫 논문의 필수 조건으로 두지 않는다. 정상공정/실증 시계열은 공정 상태·방출 경계·방호 응답 검증에 사용한다. 정상운전 시간이나 정상 벤트 횟수만으로 사고 누출 빈도를 학습하지 않는다.

빈도 기본선은 TNO 원문의 LOC 정의·조건·단위를 적용한다. 적용 가능한 부품에는 Brooks 등의 LH2 문헌 분포를 별도 대안으로 비교한다. 문헌에 근거가 없는 특수 고장모드는 별도 미산정 항목으로 유지하거나 명시한 진단 민감도 조건으로 평가하며, 임의 숫자를 기본 빈도로 승격하지 않는다.

첫 논문은 ① 표·단위·부품 노출·사건 분기 및 중복 집계 검증, ② 확보된 자료로 공정/방출/분산/피해 모델의 적용범위별 검증, ③ 문헌 빈도 불확실성에 따른 위험의 범위·기여도·설비 순위/방호 판단의 안정성을 평가한다. TNO 기본값에 근거 없는 확률분포를 붙이지 않는다. LH2 구간별 분포의 상관자료가 없으면 시설 총합의 신뢰구간이라고 표시하지 않고, 의존성 가정과 민감도 범위를 명시한다. 서로 다른 TNO/LH2 LOC는 동일 부품에 합산하지 않으며, 비교 결과에 사건 포괄 범위의 차이를 표시한다.

실시간 갱신에서는 센서가 물리 상태와 확인된 방호상태를 갱신하고, 문헌 개시 빈도는 별도 입력 층으로 유지한다. 이미 확인된 누출의 피해에는 개시 빈도를 다시 곱하지 않는다. 압력·온도·진공 신호에서 시간 가변 고장률을 만드는 함수는 검증 근거가 확보되기 전까지 사용하지 않는다.

현장 빈도에 대한 베이지안 업데이트는 장래 자료가 확보될 때 사용하는 확장 기능이다. 현재 Gamma-Poisson 입력 계약이 존재해도 실제 학습을 적용한 것으로 보고하지 않는다. 현재 주장할 결과는 **문헌 빈도 가정하의 위험평가와 그 불확실성**이며, 현장 절대 사고빈도 예측 정확도는 주장하지 않는다.

## 평가 지표

| 대상 | 지표와 시험 |
|---|---|
| source | 방출률·총질량·flash/rainout 분배, 전체 및 부분 보존잔차, 시간/공간 수렴 |
| 분산 | 농도 MAE/RMSE/bias, 도달·체류시간, 2/4 vol% 영역, 오탐/미탐, 센서 관측연산자 일치 |
| 풀 | 시간별 액체 재고·증발률·반경·dryout, 차단 후 후증발, 지면 도달 유입의 중복 장부 |
| 화재·폭발 | 열유속·열량·과압·충격량과 독립 실험. 설명되지 않은 복사 계수를 근거 없이 승인하지 않음 |
| 센서 추정 | 상태 오차, 누출/센서 고장 혼동, 오탐/미탐, 검출 지연, posterior/예측구간 coverage |
| 위험 | 사건·기상·방호 분기의 확률 폐합, 조건·시간·단위 일치, 구성 변화에 대한 결과 민감도 |
| 온라인 처리 | 통신·품질검사·추정·solver·출력 포함 p50/p95/p99, 결과 age, deadline 초과·회복시간 |

수용 임계값은 센서 불확실성·관측량·관리 판단의 비용을 바탕으로 먼저 정한다. ‘모든 값 정확도 94%’처럼 단일 지표를 전체 물리모델에 적용하지 않는다. 동일 시험의 센서들이 독립이라는 가정으로 좁은 신뢰구간을 만들지 않고 실험·세션 단위의 변동과 측정 오차를 반영한다.

## 가설과 ablation

H1은 source stage와 유한 방출 이력을 보존한 모델이 정적 유량 축약보다 도달·체류시간과 후방출 영향을 더 잘 설명한다는 가설이다. H2는 정상운전과 센서고장을 경쟁 가설로 둔 상태 추정이 단순 임계값 검출보다 오탐·미탐과 누출 추정을 개선한다는 가설이다. H3는 레짐별 축약 모델이 기준 피해·위험 지표 오차를 제한하면서 실제 온라인 지연시간을 줄인다는 가설이다. 모두 현재는 미검증이다.

시간이력 제거, 풀 tail 제거, 센서 갱신 제거, 센서고장 가설 제거, 방호상태 고정, 단일 레짐 보간을 ablation으로 둔다. 먼저 입력과 비교군·지표를 동결한 후 결과를 계산하고, 실패/미지원 경우를 분모에서 제외하지 않는다.

## 첫 구현에서 얻은 근거

범용 시설 계약, 방출 질량 장부, 텔레메트리 정규화, 외부 모델 해시/환경 고정 및 TNO reporting gate 연결을 구현했다. 실제 LH2 source와 가온 스택, 명시 지면 유입의 풀 부품을 실행했다. 이 결과는 소프트웨어 및 부품 연결 검증이며 새 독립 실험 결과가 아니다. 합성 열유속으로 계산한 TNO 피해확률을 실제 시설 위험도로 보고하지 않는다.

v0.3.0에서는 제한된 옥외 source-to-cloud-to-consequence 진단 연결 및 단일 탱크 구멍 사건의 자동 문헌 빈도 연결을 실제 실행했다. v0.4.0은 실제 native 설비 모델의 PH 기체 출구·이미 계산된 유량·명시한 종료 시계를 최종 피해에 전달했고, 정상 벤트에 사고 빈도를 붙이지 않으며 고압 source plane의 부적합을 거절했다. 현재 수평·대기압·low-Mach 기체로 제한한다. 모든 LOC/설비 디지털트윈 동적 feedback, 센서 기반 누출 추정, 물리 근거 승격 및 1 Hz 신규 계산 서비스는 아직 완료되지 않았다. 초록·결론의 검증 성능 수치는 해당 적용범위의 독립 검증과 처리시간 측정 이후 작성한다. 현장 빈도 자료 확보는 이 기본 연구 경로의 선행 조건이 아니다.
