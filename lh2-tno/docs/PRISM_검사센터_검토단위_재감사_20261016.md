## Interpretation for the general LH2 module

The reviewed map confirms a small set of pressure and temperature tag units
from the operating procedure. That is useful evidence for preparing a future
state adapter. It is not enough to bind the entire workbook to an equipment
snapshot because the remaining columns still need reviewed units, tag-to-asset
identity, pressure basis, calibration/quality records, timestamps, and an
explicit stream-to-component mapping.

The PRISM adapter therefore remains fail-closed:

1. A caller must provide an exact `tag`, `unit`, and `quality` binding for each
   selected source column.
2. The normalizer must establish the pressure basis and freshness before a
   state snapshot is accepted.
3. A normal-state row never creates a hole, release duration, isolation result,
   inventory depletion, or annual frequency.
4. A qualified equipment provider still owns the accidental-release packet;
   only that packet can enter the SLABx-LH2 consequence chain.

This result improves traceability of the real data while preserving the
general-facility scope and the literature-based frequency policy.
