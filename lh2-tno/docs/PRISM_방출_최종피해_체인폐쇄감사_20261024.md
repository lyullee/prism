# PRISM 방출→최종피해 체인 폐쇄 감사 — 2026-10-24

## 목적

이 기록은 액화수소 설비의 사고 방출 packet이 `duration_s`, 종료 근거,
재고·누출 질량을 거쳐 피해 원자와 시설 IR/F-N 조건부 합계까지 실제로
도달했는지 확인한다. 기존 packet identity 감사와 달리 마지막 피해 원자와
시설 집계값을 다시 계산해 비교한다.

## 현재 결과

| 항목 | 결과 |
|---|---:|
| 시설 campaign event | 29 |
| packet이 있는 event | 24 |
| 방출값→종료·재고 case→피해 원자까지 폐쇄된 event | 24 |
| packet 밖 수직 handoff event | 5 |
| 조건부 시설 IR 재계산 일치 | `true` |
| 조건부 시설 F/N 재계산 일치 | `true` |
| qualified provider packet | 0 |
| 시설 전체 IR/F-N 승격 | `false` |

24개 packet event는 다음을 모두 확인했다.

1. packet의 provider result digest가 case와 일치한다.
2. packet의 방출시간·available mass·cumulative mass·termination basis/provenance가 case 장부와 일치한다.
3. case의 provider identity가 risk atom으로 이어지고, atom에 최종 피해 확률과 expected-death 값이 있다.
4. 모든 risk atom을 다시 합산한 조건부 시설 IR/F-N이 저장된 시설 합계와 일치한다.

이 결과는 방출부터 최종 피해까지의 **진단 연결이 닫혔다는 증거**다. packet의 시간 단계 전체를 독립적으로 재생했다는 뜻은 아니며, 합성·screening 입력을 qualified provider로 바꾸지도 않는다. 5개 수직 handoff는 별도 provider 경계 자료만 있으므로 다른 packet으로 대체하지 않고 `HANDOFF_OR_PACKET_MISSING`으로 남긴다.

## 승격 경계

`qualified_provider_packet_count=0`, 사고 가족 범위의 partial 항목, 제한된 물리검증 범위, synthetic facility 입력이 남아 있어 시설 전체 IR/F-N은 계속 보류한다. 문헌 빈도는 별도 FrequencyPlan에서만 적용하며 packet에서 빈도를 추론하지 않는다.
