# PRISM 조건부 시설 위험 뷰 (2026-11-04)

## 목적

시설 평가 원장은 설비·사고군·기상·점화·인구·방출 종료 장부를 모두 보존하지만,
원장 전체를 디지털트윈 화면이나 후속 분석기에 직접 넘기기에는 크고 복잡하다.
`conditional_facility_risk_view.py`는 원장을 다시 계산하지 않고, 이미 계산된 위험 원자를
검토 가능한 시설 단위 출력으로 포장한다.

## 현재 출력

현재 정본 평가를 입력해 만든
`results/20261104/conditional_facility_risk_view_current.json`은 다음을 포함한다.

| 항목 | 값 |
|---|---:|
| 시설 사건 수 | 34 |
| 시설 case 수 | 44 |
| 위험 원자 수 | 176 |
| 설비별 기여 | 9개 component |
| 사고군별 기여 | 원장에 포함된 12개 family |
| 조건부 IR/F-N | 사용 가능 |
| qualified facility QRA 승격 | 불허 |

출력은 다음 연결을 한 번에 확인할 수 있게 한다.

`설비 상태 → native 방출 packet → 지속시간·차단·재고 장부 → SLABx-LH2 피해 →
기상·점화·인구 분기 → 조건부 시설 IR/F-N`

## 자격 경계

이 파일의 `status`는 `CONDITIONAL_DIAGNOSTIC_FACILITY_RISK`다.
`qualification.promotion_allowed`는 항상 `false`로 설정된다. qualified provider packet,
엄격한 사고범위, 독립 물리검증이 없을 때 누락·operator-limited case를 0 위험으로
바꾸지 않고 `coverage`와 `qualification.blocking_reasons`에 남긴다.

따라서 이 뷰는 현재 디지털트윈 운영 화면과 IJHE용 연결 증거에 사용할 수 있는
조건부 진단 출력이며, 규제용 또는 검증 완료 시설 QRA 결과라는 뜻은 아니다.

## 재현

```powershell
python scripts/build_conditional_facility_risk_view.py `
  --facility-assessment results/20261031/native_full_scope_union_pipefix_state_bound/facility_assessment.json `
  --output results/20261104/conditional_facility_risk_view_current.json
```

같은 평가 원장에서 다시 계산하지 않고 digest를 기록해 원장과 출력의 연결을 추적한다.
