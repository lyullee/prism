# PRISM 실시간 방출 경로 장부

## 목적

실시간 시설 snapshot에서 설비 상태가 실제 사고 방출 경계로 넘어갔는지,
그 방출이 언제 끝나는지, 차단인지 재고 소진인지, 재고 장부가 닫혔는지를
한눈에 확인하기 위해 `equipment_release_path`를 추가했습니다.

## 출력 계약

`FacilityRealtimeConsequenceMonitor`의 각 accepted component에는 다음 장부가
붙습니다.

```json
{
  "equipment_release_path": {
    "status": "AVAILABLE_PROVIDER_RELEASE_PATH",
    "provider_release_resolved": true,
    "boundary_count": 1,
    "duration_s": 0.2,
    "isolation": {
      "status": "WITHHELD_SYNTHETIC_HORIZON",
      "basis": "synthetic_diagnostic_horizon"
    },
    "inventory": {
      "status": "MASS_BALANCE_CLOSED",
      "available_mass_kg": 1.0,
      "cumulative_mass_out_kg": 0.2,
      "remaining_mass_kg": 0.8,
      "mass_residual_kg": 0.8
    }
  }
}
```

`boundaries`에는 provider packet의 사고 ID·설비·port·방출 종류·지속시간·
사용 가능 질량·방출 누적 질량·종료 근거·provider digest가 보존됩니다. 양단
파열은 두 endpoint를 별도 행으로 보존하면서 shared inventory를 함께 기록합니다.
액체 packet이면 phase basis와 reference area도 포함합니다.

종료 basis는 `reviewed_isolation_success`, `inventory_depletion`,
`inventory_over_600s`, `model_pressure_equalization`, `two_sided_rupture`,
`emergency_relief_discharge`를 구분합니다. 합성 horizon은
`WITHHELD_SYNTHETIC_HORIZON`으로 남고 실제 차단 성공으로 바꾸지 않습니다.
재고 소진 사고는 잔량이 질량 허용오차 안에서 0일 때만
`INVENTORY_DEPLETED`가 됩니다. pressure·temperature 신호만으로 지속시간,
누출량, 차단 성공 또는 빈도를 추정하지 않습니다.

provider resolver가 없는 정상 공정 상태는
`WITHHELD_PROVIDER_RELEASE_NOT_RESOLVED`로 기록됩니다. 이 상태는 누출량 0을
뜻하지 않으며, consequence 결과를 시설 위험으로 승격할 수 없습니다.

## 시설 집계

`aggregate.equipment_release_path_component_count`는 provider 방출 경계를
성공적으로 전달한 설비 수이고, `equipment_release_path_withheld_component_count`
는 그 장부가 없는 accepted 설비 수입니다. 이 값들은 방출 경계의 연결 상태를
감사하는 숫자이며, 시설 전체 annual IR/F-N 또는 qualified QRA를 의미하지 않습니다.

현재 외부 qualified packet과 독립 물리검증이 부족하므로 이 장부는 방출→피해
추적성을 강화하는 진단 계층으로만 사용합니다.

## 점화 branch 연결

같은 snapshot의 consequence 결과가 네 가지 옥외 점화 branch를 모두 반환하면
`aggregate.current_weather_ignition_accounting`이 설비별 확률을 보존합니다.
각 설비에 문헌 빈도 binding도 있으면 `weighted_branch_frequency_per_year`에
연간 조건·방출 branch·재실 확률까지 곱한 현재 조건 branch 발생률을 기록합니다.
점화 branch가 빠진 설비는 보류 행으로 남고, 전체 시설 F/N을 만들기 위해 0으로
채우지 않습니다. 이 branch 장부는 시설 연간 IR/F-N 승격이 아니라, provider의
점화 결과가 설비별 위험 원자에 도달했는지 확인하는 연결 증거입니다.
