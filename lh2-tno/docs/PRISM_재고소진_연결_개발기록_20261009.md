# 외부 탱크 재고 소진 종료 연결 — 2026-10-09

## 목적

기존 transient 설비 진단은 밸브를 닫는 명령 또는 합성 진단시계에서 멈췄다. 이번 단계에서는 외부 `lh2dt`의 유한 탱크와 `CommandedValve`를 PRISM이 한 구간씩 호출하고, 탱크의 남은 수소 질량이 **양수인 종료 기준**에 도달하면 방출을 끝내도록 했다.

연결 순서는 다음과 같다.

`HomogeneousTank 상태 → DynamicNetworkSimulator + CommandedValve → 구간 질량/엔탈피 → ResolvedGasRelease → SLABx-LH2/SLABx → 점화·피해 → native TNO IR/F-N`

PRISM은 외부 모델의 유량을 다시 계산하지 않는다. 외부 모델이 반환한 구간 평균 질량유량·정적 출구 엔탈피·면적을 기록하고, 그 이력이 피해 계산 계약을 통과하는지 확인한다.

## 안전한 종료 규칙

외부 탱크 모델은 질량이 0인 상태를 입력으로 받지 않으며, 현재 layered simulator에는 재고가 0이 되는 순간을 안전하게 반환하는 callback이 없다. 따라서 이번 adapter는 다음 규칙을 사용한다.

1. 초기 탱크 질량과 `threshold_mass_kg`를 확인한다.
2. 한 번에 최대 0.5초의 provider 구간만 계산한다.
3. 탱크 상태가 양수 질량을 유지하는 동안만 다음 구간을 계산한다.
4. 질량이 선언한 양수 기준 이하가 되면 그 구간의 실제 결과를 보관하고 즉시 종료한다.
5. 0 kg 상태를 만들거나 마지막 유량을 미래 시각까지 연장하지 않는다.

따라서 `inventory_depletion`은 “물리적으로 질량이 정확히 0이 됐다”는 뜻이 아니라, **외부 EOS가 허용하는 양수 상태에서 선언한 수치 종료 기준에 도달했다**는 뜻이다. 기준값은 입력·응답·종료 provenance에 모두 남는다.

## 실제 실행

실행기는 `scripts/validate_equipment_inventory.py`이며 backend operation은 `equipment_dynamic_inventory`다. 이번 진단은 일반 인터페이스를 확인하기 위한 합성 소형 탱크다.

- 유체: `ParaHydrogen`, CoolProp-HEOS.
- 초기 상태: `101000 Pa`, 액체 fraction `0.0001`, 기체 출구가 되도록 명시한 내부에너지 offset `5000 J/kg`.
- 밸브: 면적 `1.0e-5 m²`, 방출계수 `0.8`, 완전 개방 명령.
- 주변: `100000 Pa`, `288.15 K`.
- 요청 시간: 40 s, provider 최대 간격: 0.5 s.
- 종료 기준: 남은 질량 `1.3405e-4 kg` 이하.

다섯 누출 면적을 각각 독립 provider 입력으로 실행했다. `AREA_0.01%`는 `1.5 s`, `AREA_0.1%`·`AREA_1%`·`AREA_10%`는 `0.5 s`, `AREA_100%`는 `0.0625 s`에서 종료했다. 모든 사례가 양수 기준에 도달했으며, `AREA_100%`의 남은 질량은 `1.0793137152054863e-4 kg`, 누적 방출량은 `2.6236186797952155e-5 kg`이다. 다섯 사례의 최대 질량 잔차는 `1.34e-20 kg`, 최대 에너지 잔차는 `1.69e-13 J`였다. 이는 초기 질량에서 방출량과 잔류 질량이 맞는지 확인하는 보존식 결과다.

각 provider 이력은 `ResolvedGasRelease`에 전달되며, 수평 대기압 low-Mach 기체 출구 조건을 사용한다. 액체 또는 2상 출구, 고압 underexpanded jet, 밸브 작동 신뢰도, 실제 설비 보정은 이 실행의 범위가 아니다.

## 시설 위험 실행 연결

`LH2_PIPE`의 다섯 문헌 누출 면적을 각각 재고 소진 provider 이력과 연결했다. 각 누출 크기에 두 풍속 조건을 적용하여 다음을 확인했다.

- provider 재고 소진 사례: 5개.
- 방출→확산→점화별 피해→native TNO IR/F-N 사례: 10개.
- 실행 사례: 10개, 미계산 사례: 0개.
- 실행 사례의 질량 장부 최종 잔차: 모두 0 kg.
- 신규 물리 계산시간: 이번 실행에서 약 1.59–2.31 s/건, 10건 약 20.85 s.
- 다섯 문헌 빈도는 각 `LH2_PIPE` area-bin에 맞춰 한 번씩 적용했다. declared-scope 결과는 계산됐지만, 시설 치수·기상·인구·재고·threshold가 합성값이므로 실제 현장 QRA 값으로 해석하지 않는다.

결과에서 모든 실행 사례의 `termination.basis=inventory_depletion`, `synthetic_release_horizon_present=false`, `UNCOMPUTED=0`을 확인했다. 즉 이번 10건은 합성 시간에서 잘라낸 방출이 아니라 provider가 반환한 양수 재고 종료 이력을 사용했다. campaign의 declared-scope IR/F-N은 계산됐지만, 탱크·밸브 입력 자체가 합성 진단값이고 물리 검증 자료가 없으므로 실제 시설 QRA 완료나 실증 정확도 증거로 해석하지 않는다.

산출물은 `results/20261009/equipment_inventory_campaign/`의 입력, provider 응답, resolved release, campaign 결과, verification에 보관한다. 결과를 다시 계산하지 않고도 provider digest·backend digest·campaign digest를 확인할 수 있다.

## 다음 확장

이 연결은 방출 종료의 소유권을 외부 설비 모델에 돌려준 첫 단계다. 다음에는 같은 계약을 실제 탱크·배관·밸브·펌프 포트에 적용하고, 액체/2상 flash 경계, actuator 지연·실패확률, 전량 방출·양단 파열·수직 vent를 별도 사건으로 구현해야 한다. 각 사건은 지원되지 않을 때 `UNCOMPUTED`로 남기며, 빈도와 물리 결과를 임의로 대체하지 않는다.

현재도 현장 빈도 학습, 실내, 폭굉, 전체 domino, 독립 실험 검증, 1 Hz 신규 물리 계산은 범위 밖이다.
