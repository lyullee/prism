# PRISM 검사센터 자료와 외부 설비 패킷 재감사

## 목적

액화수소검사지원센터의 운전 시나리오와 별도 액화수소 설비 디지털트윈 프로젝트의 출력물을 현재 PRISM 개발 상태와 다시 대조했다. 센터 자료는 일반 액화수소 시설에 적용할 후보 사고와 모니터링 신호를 찾는 데 사용하되, 특정 센터 설비를 일반 시설의 기본값으로 복사하지 않는다.

## 검사센터 자료

`scripts/import_scenario_evidence.py`로 현재 CSV 3개를 다시 읽었다. 52개 행 중 41개는 선언한 실외 범위의 후보이고, 11개는 실내·반밀폐·시험동 성격으로 범위 밖에 남겼다. 후보 family는 `pipe_hole`, `valve_hole`, `vessel_hole`, `vaporizer_hole`, `vent_hole`, `vertical_handoff`, `inventory_over_600s`이다. 압력, 유량, 밸브 상태, 수소 검지, 온도, PSV·벤트 상태 등 후보 신호도 기록했다.

이 자료의 역할은 사고범위와 데이터 요청을 구체화하는 것이다. 각 행에는 방출 질량률, 종료시간과 종료 근거, 설비가 소유한 방출 packet, 질량·에너지 폐합, 검토된 사고빈도가 없다. 따라서 PRISM은 이 자료에서 누출 크기·방출량·빈도·시설 IR/F-N을 추론하지 않는다. 요약은 [`inspection_center_scenario_evidence_reaudit_summary.json`](../examples/inspection_center_scenario_evidence_reaudit_summary.json), 원본 재감사 결과는 `results/20261020/inspection_center_scenario_evidence_reaudit.json`에 있다.

## 외부 디지털트윈 출력물

`scripts/audit_provider_artifacts.py`로 외부 출력 아카이브의 JSON 84개를 검사했다. provider response 2개와 verification 12개가 있었지만 다음 승격 근거는 발견되지 않았다.

- `prism.provider_qualification_evidence.v1` qualification record: 0개
- 독립 물리검증을 주장하는 artifact: 0개
- 완전 시설 QRA를 주장하는 artifact: 0개

따라서 이 출력물은 현재 `EXTERNAL_ARTIFACTS_DIAGNOSTIC_ONLY`로 보존한다. 방출 계산이 실행되었거나 질량잔차가 작다는 사실만으로 실제 설비 packet 적격성이나 시설 QRA를 승인하지 않는다. 실제 승격에는 event/component/port, provider source/result digest, 별도 qualification sidecar, 독립 검증 기록이 모두 필요하다. 요약은 [`provider_artifact_audit_external_summary.json`](../examples/provider_artifact_audit_external_summary.json), 전체 감사는 `results/20261020/provider_artifact_audit_external.json`이다.

## 다음 입력

다음 단계에서 외부 설비 모델이 실제 자료를 내보낼 때는 `prism.resolved_release.v1` 또는 양단 파열용 `prism.resolved_release_set.v1`와 `prism.provider_qualification_evidence.v1`를 함께 제공해야 한다. 센서 시계열은 설비 상태의 후보 입력으로만 쓰고 누출 크기나 빈도를 역추정하지 않는다. 검토된 문헌 빈도는 별도 입력으로 유지한다.

현재 IJHE 완료 감사의 상태는 이 재감사로 바뀌지 않는다. 주요 사고범위가 아직 부분적이고, provider 적격성·독립 물리검증·시설 전체 IR/F-N 승격 조건이 남아 있으므로 `INCOMPLETE_EVIDENCE`와 시설 위험 보류를 유지한다.
