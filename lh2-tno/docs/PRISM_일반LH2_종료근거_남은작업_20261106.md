# 일반 LH2 방출 종료 근거 감사와 남은 작업

## 현재 계산 연결

현재 일반 LH2 진단 캠페인은 24개 사건을 생성한다. 24개 사건 모두에서

`설비 상태 → provider 방출 packet → 지속시간·방출질량 → SLABx-LH2 → 점화·기상 → 피해량 → IR/F-N`

의 계산 연결이 확인되었다. 이 결과는 계산 경로가 끊기지 않았다는 뜻이다. 현장 설비의 방출 종료시간이나 격리 성능을 실제 자료로 확인했다는 뜻은 아니다.

## 자동 집계 결과

`results/20261106/generic_lh2_provider_release_closure_current.json`은 24개 사건과 26개 provider packet을 검사한다.

| 항목 | 결과 |
|---|---:|
| 전체 사건 | 24 |
| provider packet 경로 | 24 |
| 내부 provider packet | 26 |
| 종료 근거가 준비된 사건 | 8 |
| 종료 근거가 열린 사건 | 16 |
| qualification으로 승격된 packet | 0 |
| 시설 QRA 승격 | 불허 |

열린 원인은 두 종류다.

- 15개 사건은 `synthetic_diagnostic_horizon`처럼 고정 진단시간 또는 압력 평형을 종료조건으로 사용한다. 실제 차단·격리 기록이 필요하다.
- 1개 사건은 `inventory_depletion`인데 provider 질량수지가 없다. 초기 재고, 누적 방출량, 종료 시 잔류질량을 provider 모델이 함께 내보내야 한다.
- 5개 저장탱크 사건은 provider 검증 sidecar의 양수 재고 임계값·잔류질량·질량잔차를 packet digest와 대조해 종료근거를 닫았다. 이 검사는 zero-mass 소진을 주장하지 않으며, provider qualification과 독립 물리검증은 여전히 열려 있다.

나머지 8개는 현재 감사 규칙상 종료 경계가 준비된 사건이다. 이 중에서도 qualification은 별도의 공급자 검토와 독립 물리검증이 필요하므로 자동으로 승격하지 않는다.

## “얼마나 더”의 의미

코드 연결 자체는 이번 범위에서 마무리 단계다. 남은 개발은 21개 열린 사건의 증거를 채우고, 그 자료로 재실행하는 일이다.

1. transfer-line, transfer-valve, transfer-pump, vaporizer와 일부 storage 사건에 실제 차단·격리시간을 연결한다.
2. inventory-depletion 사건은 provider가 초기질량·최종질량·질량수지 잔차를 출력하도록 한다.
3. 같은 packet으로 SLABx-LH2 결과를 다시 만들고 질량잔차와 종료시각을 재검사한다.
4. 실제 일반 시설의 reviewed port, 기상·점화·인구 입력을 확인한다.
5. 독립 holdout 자료로 누출·액적·풀·확산 결과를 검증하고, 처리시간을 fresh physics와 cache로 각각 측정한다.

이 다섯 단계가 끝나야 `qualified provider evidence`, `independent physical validation`, `strict facility scope`, `strict facility QRA` 네 문턱을 다시 평가할 수 있다. 현재 readiness 상태는 이 때문에 `CONDITIONAL_DIAGNOSTIC_COMPLETE_STRICT_GATES_OPEN`이다.

## 재현 명령

```powershell
python scripts/audit_generic_provider_release_closure.py `
  --packet-evidence results/20261031/native_generic_scope_packets_pipefix/packet_evidence.json `
  --packet-root results/20261031/native_generic_scope_packets_pipefix `
  --output results/20261106/generic_lh2_provider_release_closure_current.json
```

readiness 보고서에는 다음 인자로 연결한다.

```powershell
--generic-provider-closure-audit results/20261106/generic_lh2_provider_release_closure_current.json
```

이 감사는 열린 packet을 자동으로 고치지 않고, 빈도나 facility QRA를 추론하지 않는다. 따라서 실제 자료가 들어오면 같은 명령으로 결과를 갱신하면서 남은 사건 수를 즉시 확인할 수 있다.
