# PRISM 외부 LH2 위험 스윕·처리시간 감사

## 목적

`Center_LH2_Risk_Sweep_20260929`에 저장된 액화수소 탱크·PSV·TNO/HYRAM 비교 계산을 PRISM의 검증 장부에 연결할 수 있는 범위만 감사했다. 이 결과는 외부 모델 출력의 수치 폐합과 실행시간을 기록하는 screening evidence다. 실제 사고 packet, 독립 실험 검증, 또는 시설 전체 IR/F-N 결과로 승격하지 않는다.

실행기는 `scripts/audit_external_lh2_sweep.py`이고, 공통 구현은 `src/lh2_tno/external_sweep_audit.py`에 있다. 공개 요약은 `examples/center_lh2_external_sweep_audit.json`이다.

## 확인 결과

- 탱크 스윕 기록 68건과 종합 CSV 68행이 서로 일치했다.
- 탱크 계산 결과의 최대 질량 잔차는 약 `1.04×10⁻¹¹ kg`이다.
- 탱크 계산 결과의 최대 에너지 잔차는 약 `5.81×10⁻⁷ J`이다.
- TNO 정책 계산 6건은 모두 완료됐고 실행시간은 약 `0.369–0.404 s`였다. p95는 약 `0.400 s`이다.
- TNO 정책 결과의 위험도는 `ENGINEERING_JUDGEMENT` 등급이며 `IR proxy`로만 기록됐다.
- 일부 탱크 스윕은 `FAILED_BEFORE_HORIZON`으로 남아 있으며 0값이나 성공으로 대체하지 않았다.

이 자료는 방출원 상태, PSV 개방·재착좌, 방출 질량, 내부 수지와 처리시간을 점검하는 데 유용하다. 따라서 PRISM의 “신규 계산 처리시간”과 “내부 수치 폐합” 근거에는 사용할 수 있다.

## 승격하지 않은 항목

다음 항목은 이 스윕만으로 판단하지 않았다.

- 실제 설비 사고 개구·차단 이력과 provider 소유 방출 packet
- 실측 방출률·확산 농도·화염 복사열에 대한 독립 실험 비교
- 현장 인구·점유·기상 분포를 포함한 시설 IR/F-N
- 모델 출력에서 사고빈도를 역산하거나 센서 빈도를 학습하는 것

따라서 감사 상태는 `SCREENING_ONLY_EXTERNAL_SWEEP`이며 `independent_physical_validation_claim=false`, `qualified_provider_packet=false`, `facility_ir_fn_claim=false`, `frequency_inference=false`다. 질량·에너지 잔차는 모델 내부 폐합의 증거이지 외부 정확도 증거가 아니다.

## PRISM 연결 계획

1. 설비 provider가 내보낸 사고 전용 방출 이력과 이 스윕의 탱크 상태·PSV 종료 시계를 구분한다.
2. provider 방출 이력에 개구, 방향, 종료근거, 누적 질량·엔탈피가 있을 때만 `ResolvedGasRelease` 또는 `ResolvedLiquidRelease`로 변환한다.
3. SLABx-LH2/TNO 결과와 이 스윕의 `IR proxy`를 동일한 수용점·기상·점화 조건으로 비교할 때는 별도 검증 사례로 기록한다.
4. 독립 실험 또는 실제 운전 검증이 추가되기 전에는 시설 QRA 승격을 열지 않는다.
