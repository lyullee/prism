# PRISM 범위 매트릭스·시설 원장 일관성 감사

기준일: 2026-10-22
상태: `INCONSISTENT_SCOPE_LEDGER`

## 목적

PRISM은 여러 설비별 캠페인을 실행한 뒤 시설 원장으로 합칠 수 있습니다. 이때 범위 매트릭스와 시설 원장이 서로 다른 실행본을 가리키면, 한 파일만 보고 “모든 사고가 계산됐다”고 판단할 수 있습니다. 이번 감사는 두 산출물이 같은 사건·case·사고군 회계를 설명하는지 비교합니다.

감사기는 `scripts/audit_scope_ledger_consistency.py`와 `src/lh2_tno/scope_ledger_consistency.py`입니다. 이 기능은 빠진 사건의 빈도나 피해를 추정하지 않고, event ID를 임의로 고치지도 않습니다. 불일치가 있으면 시설 IR/F-N 승격을 차단합니다.

## 최신 실행

```powershell
python scripts/audit_scope_ledger_consistency.py `
  --scope-matrix results/20261022/generic_transfer_line_replacement_vertical_all_bins_two_sided_inventory_isolation_with_valve_repaired_merged_scope_matrix.json `
  --facility-ledger results/20261022/native_campaign_with_repaired_valve_transfer_line_replacement_vertical_all_bins_two_sided_inventory_isolation_facility_ledger.json `
  --output results/20261022/scope_ledger_consistency_repaired.json
```

결과는 `results/20261022/scope_ledger_consistency_repaired.json`에 저장했습니다.

| 항목 | 범위 매트릭스 | 시설 원장 |
|---|---:|---:|
| 고유 event ID | 50 | 41 |
| case | 행 합계는 사고군 중복 포함 | 80 |
| 조건부 실행 | 사고군 행에는 0건 미계산으로 기록 | 78 |
| 조건부 미계산 | 0 | 2 |
| 상태 | `matrix_complete=false` | `PARTIAL_FACILITY_SCOPE` |

매트릭스에만 존재하는 event ID와 원장에만 존재하는 event ID가 모두 발견됐습니다. 사고군별 비교에서도 `case_count`, 조건부 실행 수, 조건부 미계산 수 또는 event ID 집합이 일치하지 않는 행이 남았습니다. `liquid_two_phase`처럼 여러 사고군이 같은 case를 참조할 수 있으므로 사고군 행의 case 합계를 시설 case 수로 다시 더하지 않습니다.

## 해석과 다음 조건

이번 결과는 방출→확산→점화→피해 chain 자체가 없다는 뜻이 아닙니다. 실제로 원장에는 312개 risk atom이 있습니다. 다만 그 risk atom이 선언된 전체 사고 범위와 정확히 같은 실행본에서 왔는지 확인되지 않았기 때문에, 조건부 진단값과 적격 시설 QRA를 구분합니다.

다음 병합에서는 다음 조건을 모두 만족해야 `CONSISTENT_SCOPE_LEDGER`가 됩니다.

1. 범위 매트릭스와 시설 원장이 동일한 event ID 네임스페이스를 사용한다.
2. 각 case가 동일한 `scenario_families`를 갖고, 수직 handoff 같은 공급자 소비 사고군이 case metadata에 남는다.
3. 조건부 실행·미계산 수가 두 산출물에서 일치한다.
4. 이 일관성 결과와 별도로 provider 자격, 독립 물리검증, 실제 설비·기상·인구 근거 gate를 통과한다.

따라서 이번 감사 결과로 시설 IR/F-N을 0으로 대체하거나 미계산 사고의 빈도를 다른 사고에 재배분하지 않습니다.
