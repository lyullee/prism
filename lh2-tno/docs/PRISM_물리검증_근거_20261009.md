# PRISM 물리 검증 근거와 적용 범위 — 2026-10-09

## 판정

PRISM에 연결된 외부 DynamicLH2PoolX 자료에는 **제한된 구성요소 검증**의 근거가 있다. 이 자료는 지면에 도달한 액화수소 유입을 축대칭 풀의 증발·확산 반경으로 계산하는 경로를 검증한다. 방출원, 설비 밸브 차단, 대기 확산, 점화, 화재·폭발, IR/F-N 전체 체인의 독립 검증은 아니다.

따라서 PRISM의 전체 결과는 계속 `physical_validation_claim=false`로 표시한다. 검증 장부의 `physical_validation_claim=false`와 `full_chain_validation_claim=false`도 같은 의미다. 구성요소 근거가 생겼다는 이유로 시설 위험 결과를 검증 완료로 바꾸지 않는다.

## 재현한 증거 장부

외부 검토 저장소의 Stage-C 증거 JSON과 source manifest를 PRISM adapter로 읽었다. adapter는 evidence decision, hold-out 지표, 질량 잔차, 원자료 목록, protocol·source·모델 파일의 SHA-256을 검사한다.

실행 명령은 다음과 같다.

```powershell
python lh2-tno/scripts/validate_physical_evidence.py `
  --evidence <DynamicLH2PoolX-review>/data/stage_c_evidence.json `
  --source-root <DynamicLH2PoolX-review> `
  --output lh2-tno/results/20261009/validation_evidence/dynamiclh2poolx_stage_c_prism_record.json `
  --allow-provenance-drift
```

`--allow-provenance-drift`는 검증을 통과시키기 위한 옵션이 아니다. 선언된 해시와 현재 제공된 snapshot이 다를 때 그 차이를 기록하고, 검증 상태를 `DECLARED_EVIDENCE_WITH_SOURCE_HASH_DRIFT`로 낮추기 위한 감사 옵션이다. 엄격 모드에서는 같은 차이를 오류로 중단한다.

현재 Git blob snapshot에서 모델 코드·source manifest·관측자료의 해시는 일치했고, `data/dynamic_validation_protocol.json`의 선언 해시 하나는 snapshot과 달랐다. 그러므로 이번 장부는 수치 지표를 보존하지만 완전한 재현성 확인으로 부르지 않는다. 산출물은 `results/20261009/validation_evidence/dynamiclh2poolx_stage_c_prism_record_git_blob.json`이다.

추가로 공개 저장소 `lyullee/DynamicLH2PoolX`의 고정 커밋 `2486a2949edb63ed6b25827a980468c2b112f404`를 읽기 전용으로 재검사했다. 현재 공개 커밋의 `data/dynamic_validation_protocol.json` 해시는 `0452bf5a...`이고 Stage-C evidence가 선언한 해시는 `160072c9...`이므로 같은 불일치가 재현됐다. 이 결과는 provenance blocker로 기록하며, 제한 구성요소 검증을 전체 체인 검증으로 승격하지 않는다.

## 확인된 수치

| 구성요소 | 독립 hold-out 지표 | 결과 | 판정 |

| 물 표면, Trial 4 | 영상 구간 포함률 | `1.0` | 선언 관문 `≥0.90` 통과 |
| 알루미늄 표면, Dienhart Trial 6 | 반경 RMSE | `0.101587401 m` | 선언 관문 `≤0.15 m` 통과 |
| 알루미늄 표면, Trial 6 | 영상 구간 포함률 | `1.0` | 선언 관문 `≥0.90` 통과 |
| HSE RR985/RR986 Test 6 연결 진단 | 최대 미장부 질량 잔차 | `8.2445e-13 kg` | 장부 한계 `≤1e-9 kg` 이내 |

Trial 3과 5는 표면 계수 보정에 사용됐고 Trial 4와 6은 hold-out으로 사용됐다. PRISM 장부는 이 구분과 외부 보고서의 제한사항을 유지한다. 실험 원자료와 PDF는 재배포하지 않고 외부 검토 저장소의 경로·해시만 기록한다.

## PRISM 연결 위치

이 근거가 직접 뒷받침하는 PRISM 구간은 다음 하나다.

`지면 도달 유입 → DynamicLH2PoolX pool/spreading → 풀 질량·반경 장부`

현재 외부 검증 보고서가 제외하는 jet impact/deposition fraction, 비대칭 액편, 경사·배수·방벽·복잡 지형, 응축 공기 고체 침적, 대기 확산은 PRISM의 전체 위험 체인 검증으로 확장하지 않는다. `ResolvedGasRelease`의 설비 출구, 탱크 재고 종료, 차단 성공/실패, SLABx 대기 확산, 점화와 TNO IR/F-N은 별도의 합성 연결·보존식·계약 검증으로 기록되어 있으며, 이 풀 구성요소 증거와 합산해 물리 검증 완료라고 말하지 않는다.

## IJHE에서의 사용 문장

논문에서는 “지면 도달 후 축대칭 풀 구성요소는 공개 실험 hold-out 지표와 질량 보존 장부로 제한 검증했으며, 설비 방출·대기 확산·점화·위험 합산은 연결 검증 단계로 분리했다”라고 기술할 수 있다. “PRISM 전체가 실험으로 검증됐다”, “현장 절대위험이 검증됐다”, “1 Hz 신규 물리 계산이 입증됐다”라고 기술할 근거는 아직 없다.
