# PRISM v0.6.0 — 명칭과 상세 사용 안내

2026-10-08. 사용자 선택에 따라 **Process Risk Integration and Scenario Modeling (PRISM)**으로 명칭을 확정했다.
새 비공개 저장소 `lyullee/prism`의 main에 최신 구현과 과거 Git 이력을 보존한다.
이전 `tno-lh2` GitHub 저장소는 새 업로드·CI 검증 후 삭제 완료했다. GitHub 추가 인증은 사용자가 직접 완료했으며 인증된 API의 404를 확인했다. `tno-qra`는 생성하지 않았다. 로컬 코드와 검증 이력은 보존한다.

## 변경

- 정식 명령 `prism`, 저장소 진입점 `prism.py`, 배포 이름 `prism-risk`, 버전 0.6.0.
- standard 기본/LH2 선택 모드와 오류 시 무자동전환 정책 유지.
- `lh2-tno` 폴더·`lh2_tno` import·`tno_host`와 과거 실행 명령은 호환성을 위해 유지.
- 상세 루트 README: 시스템 구조, 개발 상태, 설치, 예제, 입력, 외부 모델 pin,
  기본 QRA, LH2 계산, 빈도, 설비 경계, 센서 API, 결과, 검증, 개발 항목, 문제 해결.
- 기존 짧은 합성 계산의 시설/요청을 examples에 복사해 clone으로 접근 가능하게 함.
- 배포 wheel의 이름과 prism entrypoint 포함 여부를 CI에서 확인.
- v0.5.0 기록 스크립트가 새 버전 상태를 덮어쓰지 않도록 버전 guard 추가.

## 검증의 의미

기존 154개 계약·보존·모드 검사와 clean tracked-source export의 154개 검사가 모두 통과했다.
wheel의 catalogue/prism 명령을 확인했고 별도 설치 환경에서 새 명령, 시설 검증, 16개 빈도 사건 예제가 통과했다. README 로컬 링크 24개와 Python 코드 블록 문법, source 요청/시설 계약도 확인했다.
검증 산출물은 로컬 `results/20261008/prism_v060`에 보관하고 코드 옆 개발기록에도 복사한다.
이번 변경은 이름/설명/packaging이며 물리 모델 범위를 확대하거나 최신 provider를 재실행한 증거가 아니다.
과거 물리 시험은 해당 버전과 source digest의 역사 기록으로 해석한다.

전체 LH2 시설 위험, 모든 LOC source 결합, 설비 누출 feedback, 현장 물리 검증과 1 Hz 새 물리 계산은 미완료/미검증이다.
문헌 빈도 + 불확실성/민감도가 기본 연구 경로이며 현장 사고빈도 수집은 개발/첫 IJHE 논문의 필수조건이 아니다.
