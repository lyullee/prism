# 외부 `lh2dt` 사고 방출 이력 연결 진단

## 목적

액화수소 설비 디지털트윈 프로젝트의 외부 `lh2dt_models`가 정상 공정상태와 유량을 계산하는 것을 확인한 뒤, 명시적인 탱크·밸브 고장 진단을 PRISM의 방출 이력 입력으로 내보낼 수 있는지 점검했다. 이 기록은 센터 설비의 사고 이력이나 현장 빈도를 만들기 위한 문서가 아니다. 외부 모델에 사고 방출 export 계약이 아직 없기 때문에, 합성 진단을 통해 필요한 연결 지점과 남은 물리 조정 항목을 재현하는 것이 목적이다.

## 확인한 외부 모델의 상태

외부 모델은 `HomogeneousTank`, `Valve`, 배관·네트워크·기화기·재액화기 등의 상태와 정상 유량 계산을 제공한다. 그러나 현재 소스와 문서에서 다음을 모두 갖춘 PRISM 사고 packet export API는 확인되지 않았다.

- 사고 원인과 고장 개구의 명시적 식별자
- 사고 시작 시각부터 실제 종료까지의 방출 이력
- 차단 성공·실패 또는 재고 소진에 따른 종료 근거
- 누적 질량·엔탈피 장부와 출구 위치·방향
- PRISM `provider_export_schema`와 exact component/port context

따라서 정상 유량 JSON이나 상태 snapshot을 사고 packet으로 바꾸지 않았다. 실제 설비의 24개 provider 요청도 여전히 `UNCOMPUTED_PROVIDER_PACKET`이다.

## 합성 진단 export

`scripts/export_lh2dt_accident_history.py`는 외부 모델에 다음을 명시하여 짧은 진단을 실행한다.

- 1 m³ 탱크, 500 kPa 포화 상태, 액체 체적분율 0.7
- 지름 0.01 m의 명시적 실패 개구와 방출계수 0.8
- 대기압 101,325 Pa, 온도 288.15 K, 3 m/s 바람
- 0.05 s 간격, 총 0.2 s의 고정 진단 시계

실행 예시는 다음과 같다.

```powershell
$py = "C:\Users\lyul\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe"
$dt = "C:\Users\lyul\Desktop\DocuData\액화수소 저장탱크_밴트 시스템\lh2dt_models"
$env:PYTHONPATH = (Resolve-Path src).Path
& $py scripts/export_lh2dt_accident_history.py `
  --lh2dt-root $dt `
  --output-dir results/20261009/external_lh2dt_bridge
```

진단은 4개 방출 구간을 만들었고, 외부 모델 질량 감소량은 `0.03191147405505035 kg`, 방출 이력 적분량은 `0.03191147405505211 kg`이었다. 질량 장부 잔차는 약 `1.76e-15 kg`로 닫혔다. 이 결과는 외부 모델의 한 진단 시계가 보존된다는 뜻이지, 실제 탱크 사고의 정확도나 시설 사고빈도를 입증하는 뜻이 아니다.

생성되는 `provider_export.json`의 schema는 `lh2dt.external_accident_export.diagnostic.v1`이다. 이는 기존 SLABx 브리지의 입력 형식이며, 아직 `prism.resolved_release.v1` 실제 provider packet으로 승격하지 않는다. 파일에는 `synthetic_diagnostic=true`, `provider_packet_promoted=false`, 현장 빈도 미추론과 물리검증 미주장이 기록된다.

## SLABx-LH2 경계 비교 결과

외부 모델이 소유한 총 유량과 SLABx-LH2가 계산한 대기 partition의 경계는 5% 상대오차 gate로 확인한다. 다음 명령은 gate를 통과시키지 못한 경우에도 모든 구간 오차와 차단 사유를 JSON으로 남긴다.

```powershell
$py = "C:\Users\lyul\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe"
$slabx = "C:\Users\lyul\Desktop\DocuData\SLABx_LH2\slabx-lh2"
& $py scripts/audit_lh2dt_slabsx_rate_boundary.py `
  results/20261009/external_lh2dt_bridge/provider_export.json `
  --slabx-root $slabx `
  --output results/20261009/external_lh2dt_bridge/slabx_rate_boundary_audit.json
```

이번 진단은 `BLOCKED_PROVIDER_SLABX_RATE_MISMATCH`였다.

| 항목 | 결과 |
|---|---:|
| 구간 수 | 4 |
| 허용 상대오차 | 5.0% |
| 첫 구간 provider 유량 | 0.159588 kg/s |
| 첫 구간 SLABx 유량 | 0.179150 kg/s |
| 첫 구간 상대오차 | 12.2573% |
| 최대 상대오차 | 12.2779% |
| provider packet 승격 | 아니오 |
| 시설 QRA 승격 | 아니오 |

기존 브리지 명령도 같은 이유로 종료 코드 1을 반환한다. 이는 한 모델의 유량을 다른 모델에 맞춰 조정해야 한다는 뜻이 아니라, 두 모델의 열역학·방출계수·액체 flash 경계가 아직 같은 물리량을 설명한다고 입증되지 않았다는 뜻이다. 따라서 계수나 빈도를 임의로 바꾸어 gate를 통과시키지 않았다.

## 현재 연결 수준

현재 구현은 다음 순서까지 재현 가능하다.

1. 외부 `lh2dt` 탱크·밸브 상태에서 명시적 합성 사고 방출 이력을 생성한다.
2. provider 시간축과 질량 장부를 검증하고 PRISM/SLABx 브리지 입력으로 저장한다.
3. SLABx-LH2에 같은 개구와 상태를 전달한다.
4. 총 유량 차이를 비교하고, 5%를 넘으면 연결을 차단한다.

아직 다음은 완료되지 않았다.

- 실제 설비의 사고 포트·고장 개구·차단 branch와 외부 모델의 매핑
- `lh2dt` 자체의 표준 사고 packet export
- `lh2dt`와 SLABx-LH2의 동일 경계 유량에 대한 물리 조정 및 독립 실험 검증
- 실제 provider packet과 문헌 `FrequencyPlan`의 exact-match 결합
- 이 외부 모델 결과를 이용한 시설 전체 IR/F-N

따라서 이 진단은 개발 연결을 앞당긴 것이지만 IJHE용 최종 물리 검증 결과는 아니다. 다음 개발은 실제 사고 export 계약을 외부 모델에 추가하고, 동일 압력·온도·상태·개구 정의로 두 유량을 조정한 뒤 독립 데이터로 flash와 방출률을 검증하는 데 집중한다.
