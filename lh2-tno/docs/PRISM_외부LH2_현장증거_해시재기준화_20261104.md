# PRISM 외부 LH2 현장증거 해시 재기준화

## 무엇을 고쳤나

PRESLHY Trial 10 현장 자료는 파일 자체가 없어진 것이 아니었다. 원본 매니페스트가 2026-10-09에 기록한 `source_boundary.csv`, `weather.csv`, `common_clock.json`의 해시와 현재 보관 파일의 해시가 달라서, PRISM은 자료를 `HASH_DRIFT`로만 사용할 수 있었다.

원본 CSV·JSON은 수정하지 않았다. 다음 도구가 현재 파일의 바이트를 다시 해시한 새 매니페스트를 만들고, 이전 선언 해시와 현재 해시를 함께 남긴다.

```powershell
python scripts/rebaseline_external_field_manifest.py `
  --manifest "C:\path\to\field-evidence-manifest.json" `
  --output results/20261104/external_field_evidence/preslhy_trial10_manifest_rebaselined.json `
  --manifest-id preslhy-e35-trial10-manifest-rebaselined-20261104 `
  --acknowledge-source-rebaseline
```

`--acknowledge-source-rebaseline`를 명시하지 않으면 실행되지 않는다. 이는 해시를 조용히 바꾸면 안 되기 때문이다. 재기준화 기록은 `independent_reverification=false`와 `promotion_allowed=false`를 고정한다.

## 새 결과

- 현장 증거: `RESTRICTED_EXTERNAL_FIELD_EVIDENCE`
- source boundary 208행, weather 92행, receptor 5,053행
- 해시 drift 채널: 0개
- 모델 비교: `RESTRICTED_FIELD_MODEL_COMPARISON`
- 센서 geometry: 31/31 일치
- 농도 비교: 4,960/5,053행 일치(98.16%)
- RMSE: 31.1029 vol%
- 독립 물리검증 claim: `false`
- 사고 방출·빈도·시설 IR/F-N claim: `false`

새 장부는 `results/20261104/external_field_evidence/preslhy_trial10_reverified.json`, 비교 결과는 `results/20261104/external_field_model_comparison/preslhy_trial10_reverified_comparison.json`에 보존했다. 검증 매트릭스와 IJHE 목표 감사도 이 두 결과를 사용해 다시 만들었다.

## 해석 범위

해시 drift가 사라졌다는 것은 현재 파일과 새 매니페스트가 같은 바이트를 가리킨다는 뜻이다. 측정자료가 독립적으로 재검토됐거나, measured-source replay가 독립 물리검증으로 승격됐다는 뜻은 아니다. 비교 결과는 풍향·축 정의·운송지연 검토가 필요한 진단자료이며, 사고 누출 구경·방출 지속시간·설비 빈도를 센서에서 역산하지 않는다.

따라서 IJHE 목표 감사의 네 엄격 차단은 그대로다.

1. 독립 물리검증
2. qualified provider 방출 packet
3. 선언한 일반 LH2 사고범위의 완결
4. 시설 전체 IR/F-N QRA 승격

현장자료는 SLABx-LH2 비교의 입력 준비와 모델 오차 진단에는 쓸 수 있지만, 문헌 빈도나 시설 위험도를 자동으로 바꾸지 않는다.

## 좌표방향 감도 장부 재연결

기존 방향 감도 결과도 이전 현장 장부 상태(`HASH_DRIFT`)를 가리키고 있었으므로, 새 현장 증거와 사건·source boundary·receptor 해시를 대조해 다시 연결했다.

```powershell
python scripts/rebaseline_external_field_orientation.py `
  --sweep results/20261103/external_field_model_comparison/preslhy_trial10_orientation_sweep_unverified.json `
  --field-evidence results/20261104/external_field_evidence/preslhy_trial10_reverified.json `
  --output results/20261104/external_field_model_comparison/preslhy_trial10_orientation_sweep_reverified.json `
  --acknowledge-rebaseline
```

네 방향의 상태는 `RESTRICTED_FIELD_MODEL_COMPARISON`으로 갱신됐고 RMSE가 가장 낮은 진단 방향은 135°(28.4666 vol%)로 그대로다. 이는 방향을 최적화하거나 채택한 것이 아니다. 공개 원자료의 x·y 방위축 정의가 없고, 네 방향 모두 `physical_validation_claim=false`, `promotion_allowed=false`를 유지한다.
