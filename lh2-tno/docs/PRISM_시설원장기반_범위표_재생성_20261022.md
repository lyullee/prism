# 시설 원장 기반 사고범위표 재생성

## 문제

2026-10-22 밸브 보완 시설 원장은 41개 고유 event와 80개 case를 보존했지만,
기존 범위표는 여러 시점의 campaign을 합친 파일이었다. 그 결과 범위표에는
이전 namespace의 event ID 50개가 남고, 원장에는 최신 namespace 41개만 남았다.
범위표의 조건부 미계산 0건과 원장의 2건도 달랐다. 이 상태에서는 숫자 계산이
실행되었더라도 두 문서가 같은 시설을 설명한다고 말할 수 없다.

## 처리 방법

`src/lh2_tno/facility_scope_matrix.py`와
`scripts/build_ledger_scope_matrix.py`는 최신 시설 원장을 단일 입력으로 받아
다음 순서로 처리한다.

1. 이미 campaign이 저장한 `scenario_families`를 보존한다.
2. 표지가 없는 event에만 저장된 `profile`과 `release.mode`로 기본 사고군을
   결정한다. 예를 들어 `LH2_PIPE`와 `hole`은 `pipe_hole`과
   `liquid_two_phase`가 된다.
3. 수직 handoff, 재고 소진처럼 event profile만으로 증명할 수 없는 사고군은
   정확한 event ID를 지정한 override가 있을 때만 추가한다. 문자열 prefix나
   임의 이름 치환은 허용하지 않는다.
4. 보정된 원장의 event·case 집합을 그대로 사용해 범위표를 새로 만든다.

이 과정은 방출량, 빈도, 피해확률, risk atom 값을 바꾸지 않는다. 보정 결과에는
`scenario_family_metadata`와 digest가 남아 어떤 event가 기존 표지에서 왔고,
어떤 event가 profile 또는 명시적 override에서 왔는지 기록된다.

## 2026-10-22 결과

```text
event count                         41
case count                          80
conditional executed                78
conditional uncomputed               2
unclassified events                  0
scope/ledger audit                   CONSISTENT_SCOPE_LEDGER
facility QRA                         withheld
```

사고군별 표는 이제 동일한 41개 event namespace를 사용한다. `pipe_hole`에는
원장의 일반 배관·재고·차단·수직 진단 및 보류 양단 event가 보이고,
`inventory_depletion`에는 재고소진 5개 event와 기존 vaporizer event가 보인다.
`vertical_handoff`와 `two_sided_rupture`도 실제 원장 event에만 연결된다.
사고군은 같은 risk atom을 여러 관점에서 보는 분류이므로 행별 빈도를 합산하지
않는다.

재현 명령은 다음과 같다.

```powershell
python scripts/build_ledger_scope_matrix.py `
  --facility-ledger results/20261022/native_campaign_with_repaired_valve_transfer_line_replacement_vertical_all_bins_two_sided_inventory_isolation_facility_ledger.json `
  --family-override "generic-lh2-full-scope-example/inventory-depletion/terminal_pipe_asset/AREA_0.01%=inventory_depletion" `
  --family-override "generic-lh2-full-scope-example/inventory-depletion/terminal_pipe_asset/AREA_0.1%=inventory_depletion" `
  --family-override "generic-lh2-full-scope-example/inventory-depletion/terminal_pipe_asset/AREA_1%=inventory_depletion" `
  --family-override "generic-lh2-full-scope-example/inventory-depletion/terminal_pipe_asset/AREA_10%=inventory_depletion" `
  --family-override "generic-lh2-full-scope-example/inventory-depletion/terminal_pipe_asset/AREA_100%=inventory_depletion" `
  --family-override "generic-lh2-full-scope-example/vertical-handoff/terminal-valve/AREA_0.01%=vertical_handoff" `
  --family-override "generic-lh2-full-scope-example/vertical-handoff/terminal-valve/AREA_0.1%=vertical_handoff" `
  --family-override "generic-lh2-full-scope-example/vertical-handoff/terminal-valve/AREA_1%=vertical_handoff" `
  --family-override "generic-lh2-full-scope-example/vertical-handoff/terminal-valve/AREA_10%=vertical_handoff" `
  --family-override "generic-lh2-full-scope-example/vertical-handoff/terminal-valve/AREA_100%=vertical_handoff" `
  --repaired-ledger-output results/20261022/native_campaign_with_repaired_valve_transfer_line_replacement_vertical_all_bins_two_sided_inventory_isolation_facility_ledger_family_repaired.json `
  --output results/20261022/facility_ledger_backed_scope_matrix.json

python scripts/audit_scope_ledger_consistency.py `
  --scope-matrix results/20261022/facility_ledger_backed_scope_matrix.json `
  --facility-ledger results/20261022/native_campaign_with_repaired_valve_transfer_line_replacement_vertical_all_bins_two_sided_inventory_isolation_facility_ledger_family_repaired.json `
  --output results/20261022/scope_ledger_consistency_family_repaired.json
```

두 번째 명령은 `CONSISTENT_SCOPE_LEDGER`를 반환한다. 이는 범위표와 시설
원장이 같은 사건·사례를 설명한다는 뜻이다. `PARTIAL_FACILITY_SCOPE`,
operator-limited packet, 미계산 2건, 실제 provider 자격 부족과 독립 물리검증
부족은 그대로 남으므로 시설 전체 IR/F-N 또는 적격 QRA를 의미하지 않는다.
