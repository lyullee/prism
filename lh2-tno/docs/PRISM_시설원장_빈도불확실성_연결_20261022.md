# 최신 시설 원장 빈도 불확실성 연결

보정된 41-event 시설 원장에
`examples/native_lh2_transfer_line_replacement_frequency_scenarios.json`의
5개 문헌 시나리오를 적용했다.

| 구분 | 결과 |
|---|---:|
| 문헌 시나리오 | 5 |
| 생성 event | 41 |
| risk atom | 312 |
| 새 물리 계산 | 0 |
| 조건부 known-atom 재가중 | 수행 |
| 완전 시설 credible interval | 보류 |

시나리오는 자산별 shared `p05`·중앙·`p95`와 event별 independent `p05`·`p95`
경계를 비교한다. 방출량·SLABx-LH2/SLABx 확산·점화·피해확률은 다시 계산하지
않고 저장된 risk atom의 initiating frequency만 바꾼다. 문헌 경계가 없는
설비는 `published`로 고정하며, provider packet이나 센서 신호에서 빈도를
만들지 않는다.

재현 명령:

```powershell
python scripts/compute_frequency_uncertainty.py `
  --ledger results/20261022/native_campaign_with_repaired_valve_transfer_line_replacement_vertical_all_bins_two_sided_inventory_isolation_facility_ledger_family_repaired.json `
  --scenarios examples/native_lh2_transfer_line_replacement_frequency_scenarios.json `
  --output results/20261022/frequency_uncertainty_family_repaired.json

python scripts/build_facility_assessment.py `
  --campaign-result results/20261022/native_campaign_with_repaired_valve_transfer_line_replacement_vertical_all_bins_two_sided_inventory_isolation_facility_ledger_family_repaired.json `
  --scope-matrix results/20261022/facility_ledger_backed_scope_matrix.json `
  --scenarios examples/native_lh2_transfer_line_replacement_frequency_scenarios.json `
  --output results/20261022/native_campaign_with_repaired_valve_transfer_line_replacement_vertical_all_bins_two_sided_inventory_isolation_facility_assessment_family_repaired.json
```

`build_ijhe_completion_audit.py --uncertainty-result`에 이 uncertainty 파일을
전달하면 `diagnostic_frequency_uncertainty_evidence=PASS`가 된다. 현재 결과의
`facility_credible_interval=false`, `complete_facility_qra_claim=false`는
의도된 fail-closed 상태다. 합성·operator-limited 방출, 2개 미계산 case, 부분
사고군과 실제 provider 자격 부족이 남아 있기 때문이다.
