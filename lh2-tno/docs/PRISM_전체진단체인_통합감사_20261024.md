# PRISM 전체 진단 체인 통합 감사 (2026-10-24)

두 감사 장부를 합쳐 선언된 29개 사건의 방출→종료·재고→최종 피해 원자 연결 여부를 한 번에 확인한다.

```powershell
python scripts/audit_combined_chain_closure.py `
  --packet-chain-audit results/20261024/native_generic_scope_vertical_chain_closure_v1.json `
  --vertical-handoff-audit results/20261024/native_generic_scope_vertical_handoff_chain_v1.json `
  --output results/20261024/native_generic_scope_combined_chain_closure_v1.json
```

현재 결과는 `FULL_DIAGNOSTIC_CHAIN_CLOSED_OPERATOR_LIMITED`이다. 24개는 packet-subset 진단 감사로 닫혔고 5개는 합성·운영자 제한 vertical handoff 감사로 닫혀, 합계 29개 사건의 진단 연결을 확인한다.

이 통합 결과는 “모든 사건이 계산 경로를 지나갔는가”를 보여준다. 다섯 vertical 사건을 qualified provider packet으로 세지 않으며, 기존 문헌 빈도를 만들거나 바꾸지 않고, 독립 물리검증·시설 전체 IR/F-N·QRA 승격도 하지 않는다.

IJHE 완료 감사에도 같은 장부를 직접 넣을 수 있다.

```powershell
python scripts/build_ijhe_completion_audit.py `
  ...기존 인자... `
  --combined-chain-closure results/20261024/native_generic_scope_combined_chain_closure_v1.json `
  --output results/20261024/ijhe_completion_audit_native_generic_scope_vertical_v13.json
```

이 옵션은 `diagnostic_combined_chain_closure` 검사를 추가한다. 통합 장부가 잘못되면 해당 검사는 `BLOCKED`로 기록하지만 `diagnostic_only=true`를 유지한다. 따라서 진단 연결이 끊겼을 때 이를 숨기지 않으면서도 합성·운영자 제한 사건을 시설 QRA로 승격하지 않는다.
