# PRISM 일반 설비 매니페스트 연결 기록

## 목적

외부 액화수소 디지털트윈은 설비 이름과 계산 결과를 제각각 내보낸다. PRISM은 그 결과를 곧바로 위험도 숫자로 바꾸지 않고, 먼저 **어떤 부품·포트·연결·운전 신호가 실제로 확인됐는지**를 검사한다. 이 공통 계약은 특정 검사센터에 고정되지 않으므로 다른 옥외 액화수소시설에도 그대로 적용할 수 있다.

구현 파일은 `src/lh2_tno/equipment_manifest.py`이며, 명령줄 점검기는 `scripts/validate_equipment_manifest.py`이다.

## 판정 방법

매니페스트는 다음 정보를 명시한다.

- 부품: 종류, ENU 위치, 수소 물성 기준, SI 파라미터, 원자료 상태
- 포트: 부품 소속, 상, 방향, 위치, 원자료 상태
- 연결: 두 포트, 연결 상태, 출처
- 시나리오: 필요한 포트와 운전 제어, 실제 관측된 제어, 알려진 제한

판정은 네 가지로 나뉜다.

| 판정 | 의미 |
|---|---|
| `EXECUTABLE` | 엄격한 PRISM `Facility`를 만들 수 있고 선언한 시나리오의 필수 포트·제어가 모두 확인됨 |
| `PARTIAL` | 구조 일부는 읽었지만 위치·물성·P&ID 포트·연결·제어 중 하나 이상이 미확인됨 |
| `UNCOMPUTED` | 특정 부품 또는 시나리오가 아직 계산 대상으로 승격되지 않음 |
| `EXCLUDED` | 현재 선언 범위(옥외 LH2) 밖의 환경이므로 제외됨 |

누락값은 0, 기본 좌표, 임의의 밸브 상태 또는 빈도 대체값으로 채우지 않는다. `EXECUTABLE`이 아닌 결과를 `RiskCampaign`에 넣어 시설 위험도로 합산하는 경로도 없다.

## 액화수소검사지원센터 자료 점검

외부 모델 루트의 다음 자료를 읽어 시설 중립 매니페스트로 변환했다.

`center_topology.json`, `center_assets.json`, `center_port_netlist.json`, `scenarios.json`

실행 명령:

```powershell
.venv\Scripts\python.exe lh2-tno/scripts/validate_equipment_manifest.py `
  --center-root "C:\경로\06_액화수소_디지털트윈_물리모델" `
  --manifest-output lh2-tno/results/20261009/equipment_manifest_audit/center_manifest.json `
  --output lh2-tno/results/20261009/equipment_manifest_audit/center_audit.json
```

2026-10-09 실행 결과:

- 상태: `PARTIAL`
- 매니페스트 digest: `4069f84f1e16beb453d68af20be25b23656832661c5a4e8b753fb89e6c13252f`
- 외부 입력 digest: `47da2de5ea8c7f86fcc7b4cb5bb9e1bdd724729c3e1f530b5240bccb6d0884d4`
- 토폴로지 부품: 20개
- 후보 포트: 21개; 선언된 확정 포트 0개
- 후보 연결: 4개; 확정 연결 0개
- 운전 시나리오: 8개; 모두 `UNCOMPUTED`
- `can_build_facility`: `false`

주요 차단 이유는 센터 자료의 가치가 없어서가 아니다. 현재 자료가 **서브시스템 토폴로지와 후보 포트** 수준이며, 실제 P&ID 태그·좌표·물성 기준·완전한 밸브/배관 순서·운전 명령의 실제 상태가 아직 확정되지 않았기 때문이다. 따라서 screening closure의 전달 가능한 기본값을 센터 실측값으로 승격하지 않았다.

## 다음 승격 조건

1. 최종 P&ID에서 모든 사고 대상 부품의 실제 태그와 포트를 확정한다.
2. 각 포트의 상·방향·ENU 위치와 연결 순서를 확정한다.
3. 설비별 물성 기준과 SI 파라미터의 출처를 연결한다.
4. 시나리오별 밸브 명령/실제 위치, 탱크 선택, 수요 경계와 상태 시계를 내보낸다.
5. 매니페스트 점검이 `EXECUTABLE`인 시나리오만 `Facility`/`RiskCampaign`에 연결한다.

이 조건이 충족되면 설비별로 문헌 LOC와 실제 방출 포트를 정확히 결합할 수 있다. 충족되지 않은 사고는 현재처럼 설비별·시나리오별 `UNCOMPUTED`로 남겨 시설 위험도에 몰래 포함하지 않는다.

## 검증

일반 매니페스트의 완전·부분·후보·실내 사례를 단위검사로 확인했다. 전체 PRISM 검사는 2026-10-09 기준 **229개 통과**했다. 이 점검은 데이터 계약과 승격 가능성만 검증하며, 외부 물리 모델의 독립 정확도나 실제 시설 QRA 완성을 주장하지 않는다.
