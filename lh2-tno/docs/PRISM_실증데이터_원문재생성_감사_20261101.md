# PRISM 실증데이터 원문 재생성 감사 (2026-11-01)

## 목적

검사센터 운전자료가 현재 상태 장부와 동일하게 다시 읽히는지 자동으로 확인했다.
이 감사는 물리모델의 정확도를 검증하는 시험이 아니라, 원본 파일이 바뀌지 않았고
정규화된 `prism.observed_equipment_state_evidence.v1` 장부를 재현할 수 있는지 확인하는
입력 무결성 검사다.

## 실행

bundled Python에는 `openpyxl`이 포함되어 있으므로 다음 두 단계를 순서대로 실행한다.

```powershell
$py = "C:\Users\lyul\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe"

& $py scripts/audit_observed_equipment_state.py `
  --manifest examples/inspection_center_observed_state_manifest.json `
  --output results/20261101/inspection_center_observed_state_evidence_regenerated.json

& $py scripts/audit_observed_state_replay.py `
  --manifest examples/inspection_center_observed_state_manifest.json `
  --evidence examples/inspection_center_observed_state_evidence.json `
  --regenerated-evidence results/20261101/inspection_center_observed_state_evidence_regenerated.json `
  --output results/20261101/inspection_center_observed_state_replay_audit.json
```

## 결과

다음을 기록한다.

- 상태: `SOURCE_REPLAY_MATCHED`
- 원본 파일 해시 일치: **3/3**
- 재생성 상태 장부 canonical digest 일치: **true**
- 상태 표본: intake 6,840개, storage vent 673개, supply/vaporizer boundary 1,442개
- 정책: state-only, 사고 시나리오 생성 false, 빈도 추정 false, 센서 빈도 학습 false,
  provider 승격 false, 물리검증 주장 false, 시설 QRA 주장 false

현재 기록된 reviewed digest와 재생성 digest는
`1f0d2dc8fe2b4c3c4f21658639a42f3501cb446bd18ce50d0cdb360dd17e21f8`로 같다.
각 원본 파일의 SHA-256은 감사 JSON의 `source_rows`에 저장한다.

## 해석 범위

이 결과는 검사센터 자료를 상태 초기조건 후보로 재현할 수 있다는 뜻이다. 정상 운전
자료만으로 누출 구경, 방출 지속시간, 차단 성공률, 사고빈도, 점화확률, 인구 노출 또는
시설 IR/F-N을 만들지 않는다. 따라서 기존 IJHE objective audit의 물리검증·qualified
provider·strict facility QRA 차단 항목은 그대로 유지한다. 원문 해시가 바뀌거나 재생성
digest가 다르면 감사기는 `SOURCE_REPLAY_BLOCKED`로 종료한다.
