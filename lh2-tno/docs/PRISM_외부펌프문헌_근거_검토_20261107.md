# PRISM 외부 펌프 문헌 근거 검토 (2026-11-07)

## 확인한 자료

검사지원센터 데이터 폴더에 다음 NASA 문헌 PDF가 추가되어 있음을 확인했다.

- `NASA 극저온 수소 피스톤펌프 시험자료.pdf`
- `NASA 액화수소 원심펌프 시험자료.pdf`

첫 문헌은 액화수소를 포함한 극저온 유체용 피스톤 펌프의 성능·캐비테이션·내구성 시험을 다루는 1959년 보고서다. 두 번째 문헌은 액화수소 원심 펌프 단의 수두-유량, 효율, 흡입 성능 및 캐비테이션 시험을 다루는 1991년 NASA 보고서다. 두 자료 모두 펌프 모델의 독립 비교에 사용할 수 있는 후보 자료지만, 현재 PRISM 설비 포트와 연결된 비교표나 재현 실행 결과는 없다.

## 현재 판정

`results/20261107/external_pump_document_intake.json`에 파일 경로, SHA-256, 파일 크기, 설비군 분류와 사용 범위를 기록했다. 판정은 다음과 같다.

`CANDIDATE_EQUIPMENT_PHYSICAL_EVIDENCE_NO_PROMOTION`

쉽게 말하면 “펌프 물리모델을 확인할 때 참고할 수 있는 원자료는 찾았지만, 아직 PRISM 위험도 계산에 바로 넣을 수 있는 검증 결과는 아니다”라는 뜻이다.

이 문헌만으로는 다음을 알 수 없거나 확정할 수 없다.

- 인수기지의 특정 펌프와 문헌 시험 펌프가 같은 형식·크기·운전 조건인지
- 사고가 났을 때 어느 포트에서 얼마만큼 방출되고 언제 차단되는지
- 잔여 재고가 어떻게 줄어드는지
- 사고 빈도를 얼마로 둘지
- SLABx-LH2 대기 확산 결과가 실험과 맞는지
- 시설 전체 IR/F-N 위험도가 얼마인지

따라서 자료를 설비 사고 방출 패킷, 빈도 근거, 시설 물리검증 또는 시설 QRA로 승격하지 않았다.

## 물리검증으로 이어지는 다음 작업

1. PDF의 표·그림을 페이지와 단위까지 보존한 시험점 표로 전사한다.
2. 각 시험점에 펌프 형상, 회전수, 흡입 조건, 토출 압력, 유량, 유체 상태를 붙인다.
3. PRISM 외부 설비 모델의 정확한 설비 ID와 포트에 시험점을 연결한다.
4. 계수 보정 없이 모델을 재실행하고, 별도의 holdout 시험점에서 오차와 불확실성을 계산한다.
5. 그 결과가 통과해도 펌프 모델의 제한적 독립 검증으로만 기록하고, 사고 방출·빈도·시설 IR/F-N 게이트는 별도 자료가 있을 때까지 닫아 둔다.

감사 코드는 `src/lh2_tno/external_document_evidence.py`, 실행기는 `scripts/audit_external_document_evidence.py`다. 이 코드는 PDF를 provider packet으로 변환하지 않으며, 문헌에서 빈도나 누출량을 추정하지 않는다.
