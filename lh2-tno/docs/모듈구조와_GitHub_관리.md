# TNO-LH2 구조와 GitHub 관리

TNO-LH2는 기존 TNO에 연결하는 별도 Python 패키지다. 기존 TNO 엔진
안에 모든 새 코드를 직접 합친 형태는 아니다. 사용자가 실행할 시스템은
통합하되, 공정·방출·분산·위험 계산의 코드 책임과 버전을 나누어 관리한다.

| 코드 | 현재 책임 |
|---|---|
| 기존 TNO 엔진 | 기존 source/화재/폭발/인명 피해, 점화·차단·기상·IR/F-N 기능 |
| `lh2-tno` | 범용 시설·포트 계약, 모델 경계 검증, LH2 모델 실행 연결, 새 문헌 빈도/사건 생성, 센서 정규화 |
| 별도 `lh2dt` | 설비 압력·엔탈피·상·재고·배관/밸브 유량과 사건 시계 |
| SLABx-LH2/SLABx | 극저온 방출/전이·분산 |
| DynamicLH2PoolX | 지면에 도달한 액화수소의 풀·증발 |

기존 TNO의 전체 사건수목/IR/F-N과 새 LH2 경로는 아직 완전히 연결되지
않았다. 새 빈도 catalogue는 검토한 TNO 표와 LH2 문헌 snapshot을 사용하며,
레거시 사건생성기를 그대로 호출하는 경로와 구분한다.

GitHub에는 이 연동 패키지의 코드·합성 예제·시험·개발 문서를 올린다.
원계측 센터 자료, 책 PDF, 외부 모델 소스 복사본, 로컬 원고·작업 출력은
포함하지 않는다. 문서의 일부 로컬 링크와 외부 실행 스크립트는 연구 PC
경로를 사용하므로 다른 PC에서는 명시 경로를 바꿔야 한다.

명칭의 LH2는 액화수소다. LN2는 액체질소이므로 이 프로젝트의 최종 이름은
TNO-LH2로 사용한다. 코드 배포 이름은 `lh2-tno`, import 이름은 `lh2_tno`다.

GitHub private 저장소는 https://github.com/lyullee/tno-lh2 이다.
`main`에는 초기 v0.3.0을 보관했고 `codex/tno-lh2-development`에서
v0.4.0 설비 출구 연결을 개발한다. 실제 native VentStack/SteadyNetwork의
수평·대기압·low-Mach 기체 출구를 이미 계산된 유량 그대로 받아
최종 피해에 전달했다. 탱크 전단 LH2 source·수직 벤트·동적 leak feedback과
전체 시설 QRA는 아직 완전 연결되지 않았다.
