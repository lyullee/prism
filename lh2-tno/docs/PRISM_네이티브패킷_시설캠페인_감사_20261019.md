# 네이티브 LH2 패킷 시설 campaign 감사

`results/20261019/generic_native_packet_rebound_campaign.json`은 24개 선언 사건의 campaign 요청을 저장된 strict `lh2dt` packet으로 다시 만든 입력이다. 이 입력에서 고속 기체인 G1은 handoff가 없는 원래 packet으로 먼저 실행해 실패를 확인했고, 이후 같은 event/component/port/source digest를 가진 명시적 압축성 plane handoff를 별도 rebind했다. 최종 실행 결과는 `results/20261019/generic_native_packet_rebound_g1_handoff_result.json`에 있고, 요약 장부는 [`examples/native_lh2dt_packet_campaign_execution_ledger_g1_handoff.json`](../examples/native_lh2dt_packet_campaign_execution_ledger_g1_handoff.json)이다. 원래 실패 장부도 [`examples/native_lh2dt_packet_campaign_execution_ledger.json`](../examples/native_lh2dt_packet_campaign_execution_ledger.json)에 보존한다.

## 확인 결과

| 항목 | 결과 |
|---|---:|
| 선언 이벤트 | 24 |
| campaign case | 24 |
| packet identity 소비 | 24/24 |
| source/result digest 보존 | 24/24 |
| 피해체인 실행 case | 24 |
| 운전자 제한 case | 20 |
| 실패 case | 0 |
| risk atom | 96 |
| 시설 전체 IR/F-N | 보류 |

G1은 원래 packet으로는 `resolved low-Mach gas exit scope exceeded; compressible/underexpanded plane adapter required`를 반환했다. 그 실패는 그대로 보존한 뒤, 별도의 `resolved_release_with_handoff.json`을 **같은 event ID·component ID·port ID·provider source digest**가 맞을 때만 재결합했다. handoff provider result digest는 바뀌었고, `prism-notional-plane-adapter:0.1.0`의 독립 검증되지 않은 근접장이라는 provenance를 잃지 않았다. 따라서 24개 case가 모두 chain까지 도달했지만 20개는 여전히 `EXECUTED_OPERATOR_LIMITED`이며, G1의 handoff도 qualified provider packet이나 물리검증 결과가 아니다.

이 실행은 패킷의 source/result digest와 provider 종료 시계를 실제 campaign 요청에 넣었다는 증거다. 20개 `EXECUTED_OPERATOR_LIMITED`는 계산값은 있지만 합성·운전자 제한 때문에 완전한 시설 위험으로 승격할 수 없는 상태다. `provider_packet_promoted=false`, `frequency_from_provider_packet=false`, `facility_qra_claim=false`, `physical_validation_claim=false`를 유지한다.

같은 최종 campaign 결과를 `build_facility_assessment.py`에 한 번만 넣어 시설 ledger도 다시 만들었다. 24개 사건·96개 risk atom이 하나의 시설 ledger로 모이고, 문헌 빈도 5개 시나리오가 저장된 atom에 재가중되지만, 20개 운전자 제한과 1개 domain-incomplete 표시 때문에 `facility_total_risk_available=false`를 유지한다. 이 실행의 조건부 진단 IR/F-N은 별도 요약 [`examples/native_lh2dt_packet_campaign_facility_assessment_summary.json`](../examples/native_lh2dt_packet_campaign_facility_assessment_summary.json)에 기록했다. 이 값은 시설 전체 위험의 자격 있는 결론이 아니라 현재 입력과 제한을 그대로 반영한 진단용 합산이다.

## 재현 명령

```powershell
$py = (Get-Item '../output/prism-export-v060-1febujhk/venv/Scripts/python.exe').FullName
& $py scripts/rebind_campaign_to_worklist_packets.py `
  --campaign results/20261015/generic_mixed_provider_campaign_rebound_worklist.json `
  --packet-evidence results/20261015/generic_lh2_provider_worklist_packet_evidence_full_diagnostic.json `
  --packet-root . `
  --output results/20261019/generic_native_packet_rebound_campaign.json

& $py scripts/run_lh2_mixed_provider_campaign.py `
  --manifest examples/generic_lh2_full_scope_manifest.json `
  --campaign results/20261019/generic_native_packet_rebound_campaign.json `
  --backend-config results/20261009/backend_config_current.json `
  --output results/20261019/generic_native_packet_rebound_result.json

& $py scripts/rebind_campaign_to_compressible_handoff.py `
  --campaign results/20261019/generic_native_packet_rebound_campaign.json `
  --handoff-packet results/20261017/vaporizer_g1_reexport_source_state/resolved_release_with_handoff.json `
  --event-id generic-lh2-full-scope-frequency-example/ambient-vaporizer/G1 `
  --output results/20261019/generic_native_packet_rebound_campaign_g1_handoff.json `
  --provenance-output results/20261019/generic_native_packet_rebound_campaign_g1_handoff.provenance.json

& $py scripts/run_lh2_mixed_provider_campaign.py `
  --manifest examples/generic_lh2_full_scope_manifest.json `
  --campaign results/20261019/generic_native_packet_rebound_campaign_g1_handoff.json `
  --backend-config results/20261009/backend_config_current.json `
  --output results/20261019/generic_native_packet_rebound_g1_handoff_result.json

& $py scripts/audit_native_packet_campaign_execution.py `
  --campaign results/20261019/generic_native_packet_rebound_campaign_g1_handoff.json `
  --result results/20261019/generic_native_packet_rebound_g1_handoff_result.json `
  --provenance results/20261019/generic_native_packet_rebound_campaign_g1_handoff.provenance.json `
  --output examples/native_lh2dt_packet_campaign_execution_ledger_g1_handoff.json
```

IJHE 감사에는 `--native-packet-campaign-ledger examples/native_lh2dt_packet_campaign_execution_ledger.json`을 추가한다. 이 검사는 실제 packet identity 소비와 실패 보존을 확인하지만, 부분 campaign을 시설 전체 QRA로 바꾸지 않는다.
