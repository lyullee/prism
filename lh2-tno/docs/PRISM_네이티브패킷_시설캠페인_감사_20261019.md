# 네이티브 LH2 패킷 시설 campaign 감사

`results/20261019/generic_native_packet_rebound_campaign.json`은 24개 선언 사건의 campaign 요청을 저장된 strict `lh2dt` packet으로 다시 만든 입력이다. 실행 결과는 `results/20261019/generic_native_packet_rebound_result.json`에 있고, 요약 장부는 [`examples/native_lh2dt_packet_campaign_execution_ledger.json`](../examples/native_lh2dt_packet_campaign_execution_ledger.json)이다.

## 확인 결과

| 항목 | 결과 |
|---|---:|
| 선언 이벤트 | 24 |
| campaign case | 24 |
| packet identity 소비 | 24/24 |
| source/result digest 보존 | 24/24 |
| 피해체인 실행 case | 23 |
| 운전자 제한 case | 19 |
| 실패 case | 1 |
| risk atom | 92 |
| 시설 전체 IR/F-N | 보류 |

실패한 사건은 `ambient-vaporizer/G1` 하나이며 원인은 `resolved low-Mach gas exit scope exceeded; compressible/underexpanded plane adapter required`이다. 고속 기체 사건을 저마하 방출로 바꾸지 않고 실패 상태를 그대로 남겼다. 별도로 저장된 저마하 참고 packet을 고속 사건에 대체하지 않는 정책이 유지된다.

이 실행은 패킷의 source/result digest와 provider 종료 시계를 실제 campaign 요청에 넣었다는 증거다. 19개 `EXECUTED_OPERATOR_LIMITED`는 계산값은 있지만 합성·운전자 제한 때문에 완전한 시설 위험으로 승격할 수 없는 상태다. `provider_packet_promoted=false`, `frequency_from_provider_packet=false`, `facility_qra_claim=false`, `physical_validation_claim=false`를 유지한다.

## 재현 명령

```powershell
$py = (Get-Item '../output/prism-export-v060-1febujhk/venv/Scripts/python.exe').FullName
& $py scripts/rebind_campaign_to_worklist_packets.py `
  --campaign results/20261015/generic_mixed_provider_campaign_rebound_worklist.json `
  --packet-evidence results/20261015/generic_lh2_provider_worklist_packet_evidence_full_diagnostic.json `
  --packet-root . `
  --output results/20261019/generic_native_packet_rebound_campaign.json

& $py scripts/run_lh2_mixed_provider_campaign.py `
  --manifest examples/generic_lh2_full_scope_manifest.json `
  --campaign results/20261019/generic_native_packet_rebound_campaign.json `
  --backend-config results/20261009/backend_config_current.json `
  --output results/20261019/generic_native_packet_rebound_result.json

& $py scripts/audit_native_packet_campaign_execution.py `
  --campaign results/20261019/generic_native_packet_rebound_campaign.json `
  --result results/20261019/generic_native_packet_rebound_result.json `
  --output examples/native_lh2dt_packet_campaign_execution_ledger.json
```

IJHE 감사에는 `--native-packet-campaign-ledger examples/native_lh2dt_packet_campaign_execution_ledger.json`을 추가한다. 이 검사는 실제 packet identity 소비와 실패 보존을 확인하지만, 부분 campaign을 시설 전체 QRA로 바꾸지 않는다.
