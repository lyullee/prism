# IJHE 액화수소 TNO 개발 진행

## 후속 업데이트: v0.2.0 전체 진단 경로 연결

같은 날 사용자 요청에 따라 방출→풀 증발→극저온 전이→SLABx 분산→화재/폭발→인명 피해→조건부 위험을 한 실행으로 연결했다. 실제 가스 및 지면 도달 액체 사례가 끝까지 실행됐으며, 신규 계산은 기체 약 3초, 풀 포함 약 7–10초 수준이다. 정규화한 센서 압력·온도 갱신과 동일 요청 조회도 연결했다. 상세 범위·68개 시험·실제 결과는 [전체 연결 완료 기록](방출부터_최종피해_연결완료_20261008.md)과 `results/20261008/full_chain`을 기준으로 확인한다.

물리/현장 검증, 매초 신규 계산, 실내·수직 전용 노즐·DDT/폭굉, 일반 기상 적분 연간 IR은 완료 판정이 아니다. 아래 내용은 v0.1.0 시점의 초기 부품 연결 기록으로 보존한다.

## 초기 기록: v0.1.0

2026년 10월 8일 KST. 범용 패키지 `lh2-tno` 0.1.0의 첫 구현과 부품 연결 검증을 완료했다. 전체 현장 위험평가 모듈이나 실시간 서비스의 완료 판정은 아니다.

마지막 부품 실행의 parent wall time은 source 약 1.08초, 벤트 약 1.70초, 풀 약 0.92초였다. 프로세스 시작·소스 해시·모델 계산·응답을 포함한 단일 부품 실행값이다. p95/p99나 전체 경로 지연시간이 아니며 1 Hz 서비스 달성을 주장하지 않는다.

열피해 연결은 합성 복사 입력을 시간 적분한 뒤 TNO 프로빗으로 변환했다. 그 수치를 실제 화재 또는 시설 피해확률로 해석하지 않는다. 기존 화재 복사모델의 22.7 계수 문제는 여전히 남아 있다.

## 새로 확인한 전이 제한

0.2 m³ 부품에 1초·0.2초 간격의 내부 과도 source 계산을 요청했지만 HEM/HNEM 모두 1개 노드만 반환했다. 요청한 시간 범위에 대한 종료 상태와 이후 무방출 경계를 전달받지 못했으므로 마지막 유량으로 남은 시간을 채우지 않았다. 전체 이력 결과는 보류했다. 현재 기록만으로 이 종료가 물리적 무방출, 적용범위 또는 수치 문제 중 무엇인지 확정하지 않는다.

외부에서 명시한 상류 상태 이력은 구간별 source 호출과 누적 장부로 연결했다. 이 방식은 관측/탱크 solver 경계 전달을 지원하지만, 실제 탱크 동역학·전체 에너지 수지를 풀거나 검증했다는 뜻은 아니다.

| 항목 | 상태 | 다음 완료 조건 |
|---|---|---|

| D02 일반 시설 스키마 | 소프트웨어 구현·시험 완료 | 실제 시설 입력의 확정은 개별 시설 적용 때 수행 |
| D03 방출·물성 계약 | 핵심 구현 | EOS/기준 불일치·질량 중복·재고 초과 차단. 전체 에너지/운동량 전이 폐합 필요 |
| D04 센서 어댑터 | 핵심 구현 | 출처·품질·단위·시각 및 압력기준 처리. 센터 메타데이터와 데이터 재생 연결 필요 |
| D05 근거 gate 연결 | 새 source 경로에 연결 | 기존 전체 TNO pipeline의 gate 승격과 실제 검증 records 등록은 미완료 |
| D07 탱크–벤트 동적 연결 | 벤트 부품 호출 완료 | 탱크·PSV·배관의 상태 및 실제 출구 경계를 동적으로 연결 |
| D08 임계 방출·상분배 | 기존 source 실행 연결 | 독립 source 실험과 전체 에너지/시간 이력 검증 |
| D09 풀 연결 | 명시 지면 유입의 부품 호출 | 제트 도달량·공간 footprint의 물리 계약과 연결 |
| D10 최신 SLAB API | 미완료 | 현재는 상류 source만 연결. 동결 농도장 경로의 일반 API와 재현 필요 |
| D12 화재·복사 | 피해 변환만 연결 | 검증된 복사/화염 모델과 source 장부의 연결 |
| D17 빈도 라이브러리 | 계산 입력 규칙 구현 | 부품 빈도/분모/prior의 실제 라이브러리 및 노출량 갱신 |
| D18 단기 위험 | 확률 연산 핵심 구현 | 관측 posterior·점화/방호·피해장과 실제 연결 |
| D19–D23 실시간·논문 검증 | 프로토콜 수립 | 기준 solver 완성, 독립 데이터, 온라인 축약과 전체 경로 성능 |

D06 및 나머지 상태 추정·누출 역추정·방호신뢰도·확장 항목은 이후 구현 대상으로 유지한다. 단위시험 수나 개별 부품 실행을 전체 완성률로 환산하지 않는다.

## 다음 물리 연결 순서

1. 내부 과도 source 종료 상태/종료시각/무방출 경계의 의미를 감사하고, 일반 탱크·벤트 solver에서 전달할 경계 이력을 고정한다.
2. source의 가스 발생 위치·액적·운동량·엔탈피를 제트–구름 전이로 전달한다. 비행 중 기화된 가스를 모두 노즐 원점에서 발생한 가스로 놓지 않는다.
3. 실제 지면 도달 위치·유입률과 검증된 footprint를 풀 모델에 전달한다. source에 지면 도달 액체가 없으면 풀을 생성하지 않는다.
4. 같은 경계·관측연산자로 SLAB 농도장을 재현하고, 화재/점화 및 단기 위험과 연결한다.
5. 센터의 시간/압력/센서 위치 메타데이터를 확정한 홀드아웃 재생, 외부 실험과 전체 경로 지연시간을 평가한다.
