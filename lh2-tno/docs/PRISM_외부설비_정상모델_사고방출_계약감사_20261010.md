# PRISM 외부 액화수소 설비 모델의 정상상태·사고방출 계약 감사

검토일: 2026-10-10  
대상: `액화수소검사지원센터 모델링` 프로젝트의 액화수소 설비 디지털트윈 출력과 PRISM의 일반 액화수소 시설 위험평가 경계

## 결론

외부 디지털트윈은 탱크·배관·밸브·벤트·펌프·기화기·재액화기 등의 정상 공정상태와 동적 네트워크 보존을 계산한다. 이번 보완에서 각 사고 대상 클래스에 `export_accident_history(request)`를 추가했다. 이 메서드는 PRISM adapter가 유량을 재계산하는 대신, 외부 클래스의 실제 `simulate`·`step`·`evaluate` 계산을 호출해 방출 시간 이력과 질량/엔탈피 원장을 반환한다. 응답은 합성·진단 입력이므로 qualified 사고 packet으로 자동 승격하지 않는다.

이번 감사 결과는 다음과 같다.

| 구분 | 결과 | 의미 |
|---|---:|---|
| 외부 모델 클래스 | 8개 바인딩 소스 확인 | 정상상태 모델 소스는 존재한다 |
| 외부 native 사고 export | 7/7개 | 7개 외부 클래스가 `export_accident_history(request)`를 제공하며 PRISM strict adapter가 이를 검증한다 |
| PRISM 진단 adapter | 7개 계약 확인 | 합성·진단 packet을 만들 수 있지만 현장 적격 packet은 아니다 |
| qualified provider packet | 0개 | 설비별 재고·차단·종료·독립검증이 결합된 packet은 없다 |
| 빈도·시설 IR/F-N | 승격하지 않음 | 이 감사는 빈도를 추정하거나 시설 QRA를 열지 않는다 |

따라서 정상 공정상태→사고 방출→피해 chain의 코드 연결은 **native 진단 연결**로 확보됐다. 남은 과제는 현장 상태 snapshot과 native accident request의 정확한 설비 ID/포트 매핑, 검토된 종료 근거, 독립 물리검증, 자격 packet, 전체 사고범위다.

## 무엇은 이미 연결됐는가

외부 모델 출력에서 다음을 읽고 PRISM의 진단 근거로 사용할 수 있다.

- 층상 탱크의 액체·기체 셀과 상태량
- 배관·밸브·펌프·기화기·재액화기의 정상 상태와 동적 step
- 공통 시계, 유량, 누적 질량·에너지 장부
- 8개 합성 운전 시나리오의 보존 검사
- 20261008 탱크 시험 패키지와 두 저장탱크 `TK-1101`, `TK-1102`의 재현 정보

이 값들은 `upstream_port_state`로 전달할 후보가 된다. 포화 상태에서는 P–T만으로 액체·기체를 구분할 수 없으므로 압력·엔탈피·phase/quality·셀 식별자를 함께 보내야 한다. 이미 계산된 유량을 다시 구멍 크기만으로 계산하면 안 된다.

## 무엇이 아직 없는가

외부 모델 소스 감사에서 모든 설비 클래스에 대해 다음이 확인되지 않았다.

- 사고 요청을 받는 native `export_accident_history(request)`
- 사건별 `component_id`·`port_id`·상·셀의 정확한 사고 경계
- 차단 시각을 포함한 방출 시간 이력
- 재고 소진 또는 허용 잔량에 대한 종료 근거
- 구간·누적 방출 질량 및 에너지 원장
- 독립 검증과 실제 설비 조건을 함께 가진 qualified provider packet

PRISM의 `scripts/export_lh2dt_*_prism_packet.py` adapter는 위 공백을 진단용으로 메우지만, 소스 모델의 사고 export가 되었다고 주장하지 않는다. 현재 IJHE 완료 감사의 `equipment_model_binding_to_accident_release` 검사는 이 외부 계약 감사가 들어오면 native export가 없는 경우 차단된다.

## 다음 구현 순서

1. 외부 모델의 7개 native export에 현장 설비 ID·포트·상태 snapshot을 연결하고, 모든 사고 family에 대해 검토된 종료 근거를 채운다.
2. 정상 운전 stream과 사고 release를 `event_kind`와 `event_id`로 분리한다.
3. 액체·기체·수직 벤트 포트를 각각 보존하고 P–h·phase/quality를 검증한다.
4. 밸브 차단, 재고 소진, 잔량 기준을 방출 packet과 설비 장부 양쪽에 기록한다.
5. 동일 packet을 SLABx-LH2·점화·피해·시설 집계로 넘기되, qualified provider와 독립 물리검증이 생길 때까지 시설 IR/F-N은 계속 보류한다.

이 계약이 채워지면 설비별 결합은 가능하다. 그때도 문헌 빈도는 별도 입력으로 유지하며, 센서 상태를 빈도로 역추정하지 않는다.
